# slide-spec.md — схема per-slide спека

Центральный контракт карусели. На эту схему ссылаются `SKILL.md` и все платформенные брифы.

---

## Схема полей слайда

Каждый слайд описывается семью полями:

| Поле | Тип | Описание |
|---|---|---|
| `№` | число | Порядковый номер слайда в карусели (1, 2, 3 …) |
| `роль` | enum | Функция слайда: `обложка` / `ценность` / `CTA` |
| `заголовок` | строка | Главная фраза слайда — крупный акцент |
| `текст` | строка | Тело слайда: пояснение, аргумент, список пунктов |
| `подача` | enum | Количество и размер текста на карточке — см. словарь ниже |
| `лейаут` | enum | Структурный шаблон карточки — см. словарь ниже |
| `визуал-направление` | строка | Описание фоновой иллюстрации / фото; одновременно промпт для image-gen |

---

## Словарь «подача» (text-treatment)

Управляет тем, сколько текста помещается на карточке и каким кеглем он набирается.

| Значение | Описание |
|---|---|
| `мега-текст` | Текст на всю карточку огромными буквами (≈ 3 слова), бренд-значок в углу. Максимальный визуальный удар, минимум слов. |
| `заголовок+треть` | Заголовок крупно + текст занимает ~1/3 высоты карточки. Баланс между читаемостью и воздухом. |
| `плотный-текст` | Компактный набор, слов больше. Подходит для чеклистов, сравнений, нумерованных шагов. Кегль уменьшается, строки ужимаются. |

---

## Словарь «лейаут»

Закрытый набор из четырёх шаблонов — ровно те, что умеет рендерить скилл
`carousel-render`. Расширять нельзя: незнакомый лейаут = спек, который не
собрать в картинку.

| Значение | Характер |
|---|---|
| `обложка` | Полноэкранный заголовок Oswald + подзаголовок. Виды: `текст`, `декор` (значок в углу), `фото` (снимок на весь кадр) |
| `тело` | Светлая карточка, 1–4 абзаца, выделения `**…**`, опциональная стрелка-нить |
| `тело-список` | Заголовок + подзаголовок-боль + пункты `**имя** — что даёт` + подвал курсивом |
| `CTA` | Тёмная карточка: крупная подпись сверху, текст призыва по центру, без бейджа «ЛИСТАЙ» |

Подпись автора и бейдж «ЛИСТАЙ» в спеке не описываются — их подставляет тема
рендера по площадке (у Instagram хэндл одной строкой, у LinkedIn имя с
должностью).

---

## Правило fits-card

> **Текст ДОЛЖЕН помещаться на карточке при выбранной подаче.**
> Формат по умолчанию — **4:5, 1080 × 1350 px**.
> Это правило важнее любого счётчика слов.

Практические следствия:
- При подаче `мега-текст` — не больше 3–5 слов суммарно (заголовок + текст вместе).
- При подаче `заголовок+треть` — заголовок до 7 слов, текст до 25–30 слов.
- При подаче `плотный-текст` — текст до 50–60 слов; если больше — дробить на два слайда.
- Если контент не вписывается в одну карточку, скилл разбивает его на дополнительный слайд с ролью `ценность`.

## Пример заполненного спека (3 слайда)

**Тема примера:** «Нейросети для контента — что уже работает прямо сейчас»

### Слайд 1 — обложка

```
№: 1
роль: обложка
заголовок: "ИИ пишет посты за 3 минуты"
текст: "Вот что я тестировал последние 30 дней"
подача: заголовок+треть
лейаут: обложка
визуал-направление: тёмно-фиолетовый градиент (#1a0533 → #3d1a6e), тонкая сетка нейросети из светящихся точек на фоне, логотип / имя автора внизу по центру — минималистичный white-on-dark
```

### Слайд 2 — ценность

```
№: 2
роль: ценность
заголовок: "3 инструмента, которые реально экономят время"
текст: "· ChatGPT — черновик поста за 2 минуты\n· Midjourney — обложка без дизайнера\n· Whisper — расшифровка войса в текст"
подача: плотный-текст
лейаут: тело-список
визуал-направление: светлый нейтральный фон (#f5f5f5), три иконки инструментов слева от каждого пункта (плоский стиль, фиолетовый акцент), брендовая полоса сверху
```

### Слайд 3 — CTA

```
№: 3
роль: CTA
заголовок: "Сохрани — пригодится"
текст: ""
подача: мега-текст
лейаут: обложка
визуал-направление: насыщенный фиолетовый фон, крупная стрелка «сохранить» в центре, бренд-значок в правом верхнем углу, минимум деталей
```

## Рендер-контракт

Вместе с таблицей для человека положи рядом **`slides.json`** — его читает скилл
`carousel-render`. Парсить markdown-таблицу хрупко, поэтому машинный вход
отдельный. Таблица остаётся для автора, JSON — для рендера.

```json
{
  "meta": { "название": "Агент. Харнес. Loop.", "площадка": "IG", "тема": "theme.json" },
  "слайды": [
    { "№": 1, "лейаут": "обложка",
      "заголовок": "Агент.\nХарнес.\nLoop.",
      "подзаголовок": "Звучит как высшая математика. Внутри — три простые штуки." },

    { "№": 2, "лейаут": "тело",
      "блоки": ["Мозг, который только **болтает**",
                "Он выдаст код и **замолчит**.",
                "А теперь смотри"],
      "нить": true },

    { "№": 3, "лейаут": "тело-список",
      "заголовок": "Разработка",
      "подзаголовок": "Проект не разваливается на пятой правке.",
      "пункты": ["**superpowers** — не бросишь на середине"],
      "подвал": "→ Твой отдел разработки" },

    { "№": 9, "лейаут": "CTA",
      "блоки": ["Хочешь разбираться в AI без магии — подписывайся."] }
  ]
}
```

Правила заполнения:

- **`**…**` — выделение, один маркер на все случаи.** Смысл подставит лейаут:
  в теле жирное начертание, на обложке акцентный цвет. Не думай про цвет,
  думай «что выделить».
- **`\n` в заголовке — принудительный перенос строки.** Ставь там, где разрыв
  осмысленный и работает на удар.
- **`нить: true`** — стрелка `⇢` в конце последнего блока. Приём «разрез фразы
  через свайп» из `carousel-backbone.md`; поле, а не символ в тексте.
- **`площадка`** — `IG` или `LI`. Выбирает блок подписи, больше ни на что не
  влияет.
- **Обложка с фото:** `"вид": "фото"`, `"фото": "имя-файла.jpg"` рядом со
  `slides.json`. Подпись с аватаркой гасится сама — автор уже на снимке.
- Полная схема с обязательными полями каждого лейаута —
  `skills/carousel-render/references/layouts.md`.

Дальше на просьбу «отрендери» управление уходит в `carousel-render`. Логику
рендера здесь не описывай.

## Заметки

- `визуал-направление` — это одновременно промпт для image-gen (Midjourney, Ideogram, DALL-E и др.). Формулируй описание так, чтобы его можно было вставить в генератор напрямую.
- `лейаут` — стабильный словарь: не расширяй его внутри карусели. Если нужен новый шаблон — добавь в словарь отдельно и обнови Figma-компонент.
- Поля `заголовок` и `текст` разделены намеренно: это разные типографические зоны на карточке с разным кеглем и весом.
