# carousel-script — где применять

Скилл превращает идею или тезис в готовую карусель для Instagram и/или LinkedIn: цепляющая обложка, одна ключевая мысль, раскладка по слайдам с атомизацией, плюс per-slide спек для рендера. Результат — артефакт карусели, а не объяснение темы.

## Когда срабатывает

- **Карусель / пост-карусель** — кидаешь идею со словами «сделай карусель», «карусель для инсты/линкедина», «пост в слайдах», «придумай карусель» → получаешь готовую карусель с per-slide спеком.
- **Перенос референса** — приносишь чужой пост со словами «хочу себе такой». Это порт формата, а не новый бриф: структура и объём сохраняются, меняется состав. Проверка годности референса идёт до раскладки — [references/reference-transfer.md](references/reference-transfer.md).

НЕ для коротких видео (это reels-script), длинных видео или обычных текстовых постов.

## Две платформы

**IG** — живой тон, провокация; объём по типу: нарратив ≤7 карточек, перечислялка — по числу пунктов, лимит не применяется. **LinkedIn** — профессиональный инсайт, 8–12 слайдов, главный CTA живёт в подписи поста, а не на слайде. Брифы — [references/instagram.md](references/instagram.md) и [references/linkedin.md](references/linkedin.md). Платформа не указана — генерируются две отдельные версии.

## Что выдаёт

Карусель по слайдам, per-slide спек (схема полей — [references/slide-spec.md](references/slide-spec.md)), `slides.json` для рендера, метастрока, строка **«Опора:»** (на какое доказательство опирается обложка) и строка **«Факты:»**. Подпись к посту идёт в комплекте — её пишет `post-hq`, карусель без подписи не публикуется.

## Рендер — opt-in

Спек и `slides.json` выдаются всегда. Дефолт — ручной режим: берёшь спек и собираешь слайды сам. По явной просьбе («отрендери», «собери карточки») `slides.json` уходит в скилл [carousel-render](../carousel-render/), который снимает PNG 1080×1350 через headless Chrome (LinkedIn — PDF-документ).

Картинки этот скилл не генерирует и не рисует: карточки с текстом генеративными моделями не собирают, буквы уезжают.

## Пример вызова

```
сделай карусель про то что большинство людей используют ChatGPT неправильно
```

```
переделай эту LinkedIn-карусель про тайм-менеджмент под нишу ИИ-инструментов
```

В ответ — карусель по слайдам (обложка + тело + CTA), per-slide спек, `slides.json`, метастрока, «Опора:», «Факты:» и блок «Допущения».
