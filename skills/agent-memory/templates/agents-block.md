## Память

Ты не помнишь прошлые окна — помнят файлы. Подробности — скилл `agent-memory` (`~/.agents/skills/agent-memory/SKILL.md`).

- **В начале работы** найди память проекта. Проект — корень git папки окна, без git — сама папка
  окна. Его память — папка в `~/.agents/memory/`, где в `MEMORY.md` есть строка
  `Проект: <полный путь проекта>`. Найти:
  `p=$(git rev-parse --show-toplevel 2>/dev/null || pwd); grep -lxF "Проект: $p" ~/.agents/memory/*/MEMORY.md`
  Прочитай этот `MEMORY.md` — оглавление памяти; заметки по теме разговора прочитай до ответа.
  Потом прочитай `PROGRESS.md` в корне проекта. Чего-то нет — памяти пока нет, это норма.
- **Узнал то, что пригодится в следующих окнах** — кто человек, его поправку или одобренный подход,
  решение и почему, где что лежит, — запиши заметку сам, не дожидаясь просьбы, и строку в
  оглавление. Как — скилл `agent-memory`.
- **Закончили шаг** или человек сказал «запиши, где остановились» — перепиши `PROGRESS.md`: что
  сделано, на чём стоп, что дальше. Где остановились — только туда, в память не пиши.
- Пароли, ключи и чужие личные данные не записывай никуда.
- Память Claude Code по проекту лежит в `~/.claude/projects/`. Читай, когда человек попросит
  (скилл `agent-memory`, «Память Claude Code»); не меняй.
