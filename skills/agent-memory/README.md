# agent-memory — где применять

Память агента между окнами для Kimi Code, OpenCode, Codex и других программ — такая же, как
встроенная память Claude Code. Новое окно сразу знает, кто ты, что решили и почему и где
остановились. Говоришь «продолжаем» — и работа идёт с того же места.

## Как устроено

Компьютер помнит тебя и проект, проект помнит работу.

| Что | Где | Кто пишет |
|---|---|---|
| Главный файл: кто ты и правила памяти | `~/.agents/AGENTS.md` | ты; при установке — агент |
| Память проекта: о тебе, твои поправки, решения и почему, где что лежит | `~/.agents/memory/<имя проекта>/` | агент сам, без просьбы |
| Где остановились | `PROGRESS.md` в папке проекта | агент, в конце шага |
| Что на потом | `BACKLOG.md` в папке проекта | агент, когда заметил что-то не по задаче |

- Одна память на все программы: сменил программу — память осталась.
- Главный файл программа кладёт в каждое окно сама: Kimi Code читает его напрямую, Codex и
  OpenCode — через ярлыки, которые ставит установка.
- Claude Code живёт на своей встроенной памяти, скилл её не трогает. Попросишь — прочитает или
  перенесёт её в общую.

## Поставить

Скажи агенту в любой программе:

```
Поставь память агента из хаба github.com/wolkart/aifuture_hub: склонируй его в ~/aifuture_hub,
подключи скилл skills/agent-memory ярлыком в ~/.agents/skills и поставь память по его SKILL.md,
раздел «Установка».
```

Агент спросит, в каких программах ты работаешь, и подключит каждую. Чужие настройки не затирает:
сначала покажет, что в них.

Проверка — новое окно в любом проекте: «Что ты обо мне помнишь и где мы остановились?» На первом
проекте правильный ответ — «памяти пока нет».

## Просьбы в окне

- «продолжаем» — в начале окна;
- «запиши, где остановились» — в конце шага;
- «запомни …», «что ты обо мне помнишь?», «забудь …».

## Чего не делает

- Не синхронизирует память между компьютерами: она лежит локально, перенести можно папкой
  `~/.agents/memory`.
- Не хранит пароли, ключи и чужие личные данные.
- Не гарантирует, что слабая модель сама откроет память: главный файл в окно кладёт программа, а
  память и `PROGRESS.md` модель открывает по правилу. Страховка — «продолжаем».
