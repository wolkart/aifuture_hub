# agent-memory — где применять

Память агента между сессиями. Скажешь «зафиксируй» — агент запишет, что решили,
почему так, а не иначе; в следующей сессии вы продолжите, как будто её не было:
агент не переспрашивает принятое и не предлагает уже отвергнутое.

Работает на любом агенте, который читает инструкции из файлов (Claude Code,
Kimi Code и аналоги).

## Три операции

- **ПОСТАВЬ ПАМЯТЬ** — один раз на компьютер: агент создаёт хранилище
  `~/.agents/memory/`, блок-указатель в глобальном файле инструкций
  (`~/.agents/AGENTS.md`, у Claude Code — `~/.claude/CLAUDE.md`) и индекс первого
  проекта. После установки скилл не нужен для работы: указатель грузится сам.
- **ЗАФИКСИРУЙ** — в любой момент: агент пишет заметку по шаблону (решение →
  почему → как применять) и добавляет строку в индекс проекта. Индекс грузится
  в каждую сессию этого проекта, заметки — по требованию, когда тема всплыла.
- **ПЕРЕНЕСИ ПАМЯТЬ ИЗ КЛОДА** — скопировать готовую память Claude Code
  (`~/.claude/projects/*/memory/`) в общее хранилище. Формат заметок совпадает,
  перенос — копирование, не переработка. Чужие файлы не изменяем.

## Чего внутри нет намеренно

- Нет хранения памяти внутри проектов: файлы не мусорят в папках, ничего не надо
  прятать в `.gitignore`, приватные заметки не утекают в публичный репозиторий.
- Нет глобального индекса на все проекты: в сессию грузится только индекс текущего
  проекта — экономия токенов и контекста.
- Нет записи «по каждому событию»: заметки пишутся по команде и при явных
  договорённостях, иначе индекс превращается в шум.

## Что даёт / чего не делает

- Даёт: продолжение работы между сессиями без пересказа контекста и скилл,
  которым можно поделиться — ученик передаёт агенту папку скилла и говорит
  «поставь память».
- НЕ заменяет резюме в конце сессии: «зафиксируй» записывает выводы, а не
  пересказывает разговор.
- НЕ синхронизирует память между компьютерами: хранилище локальное, для
  переноса — архивом или через git.

## Подключение

Claude Code: симлинк этой папки в `~/.claude/skills/` (см. [install-skills.sh](../install-skills.sh)
в корне `skills/`). Kimi Code: симлинк в `~/.agents/skills/`. После подключения
скажи агенту «поставь память».
