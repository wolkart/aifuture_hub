# hook-base — где применять

Скилл — **библиотека+резолвер хуков**: хранит сильные хук-паттерны по единой схеме и быстро отдаёт лучшие под конкретный ролик. Не пишет сценарии/посты и не анализирует профили — только хранит и подбирает хуки.

## Две операции

- **ПОЛОЖИТЬ** — диктуешь хук словами: «внеси хук „…"», «залетел ролик, хук был такой-то», «увидел классный хук, добавь». Скилл молча классифицирует по схеме (тип/ниша/формат/шаблон/когда работает/кросс-нишевость/источник/метрики), кладёт запись и отвечает одной строкой `Записал: …`. Скрапер (instagram-analytics) — лишь один из источников, не единственный.
- **ВЗЯТЬ** — просишь хук под тему: «дай хук под рилс про…», «подбери хук для карусели про…». Скилл отбирает по механике, ранжирует **по величине просмотров** и отдаёт **5 кандидатов**. Пусто по теме — честно говорит и отдаёт управление.

reels-script и carousel-script при резолве хука/обложки вызывают этот скилл (операция ВЗЯТЬ); типы хуков из `craft-law` остаются фоллбэком.

### Как ВЗЯТЬ обращается с фразой

**Работает дословная фраза из записи, а не скелет со слотами.** За ней измеренные просмотры, за переформулировкой — ничего. Ниша не фильтрует и не понижает: хук из фитнеса заходит на ИИ, если механика цепляет.

Единственный случай, когда дословно нельзя, разводится существующим законом, а не шаблонизацией. Вопрос к фразе один: **утверждает ли она что-то про автора или про чужой конкретный факт?**

- Нет → берётся **как есть**, меняются только названия предметов.
- Да — чужой опыт, встреча, разговор, личная цифра («этот индус рассказал мне, что все его друзья ушли с GPT») → переносится **механика, слова свои**: `copy-law` §5 запрещает враньё про живого человека.

Под каждым хуком идут просмотры и пометка `дословно` / `механика: <какая>` — автор проверяет одним взглядом, не соврали ли за него и не пересказали ли чужую фразу от лени.

Легло меньше пяти — отдаётся меньше, с указанием, чего не нашлось. Натянутый хук портит тест: съёмка потрачена, а что мерили — непонятно.

## Где склад

- **Рабочая база хуков** — путь не зашит в скилл. Используй только тот путь, который пользователь явно указал в своей проектной конфигурации. Если путь не задан, не записывай в личные файлы автоматически.
- **Фоллбэк** — если волта нет (харнес забрал другой человек): `references/patterns/` в репо с обезличенным примером-затравкой. Свой склад такой человек наполняет сам.

Схема записи, правила молчаливой классификации и конвенция имён — в [references/schema.md](references/schema.md).

## Пример вызова

```
внеси хук: "90% людей используют ChatGPT как поисковик"
```
```
дай хук под рилс про то, что вайб-кодинг без понимания опасен
```
