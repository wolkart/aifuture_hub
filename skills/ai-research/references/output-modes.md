# Форматы выхода режимов ai-research

Четыре режима скилла производят структурированный выход, готовый к дальнейшему использованию — посту, рилсу, карусели или передаче в другой скилл.

---

## Режим `ideas` — пул идей для контента

**Назначение:** генерация ранжированного списка тем для постов/рилсов/каруселей на основе свежих AI-новостей.

**Поля каждого кандидата:**

```
N. Тезис
   · Угол: <точка зрения или нарратив>
   · Почему зайдёт: <боль аудитории / тренд / провокация>
   · Формат: рилс | карусель | пост | обе
   · Источник: <название — URL>
```

**Пример (2 идеи):**

```
1. GPT-5 умеет рассуждать медленно — и это меняет всё
   · Угол: объясняю, чем «медленное мышление» отличается от обычного ответа
   · Почему зайдёт: создатели контента не понимают разницу и упускают фичу
   · Формат: карусель
   · Источник: OpenAI — openai.com/news/

2. Open-source обогнал GPT-4 по бенчмаркам: что это значит
   · Угол: провокация — нужны ли платные API в 2025?
   · Почему зайдёт: боль подписной платы + тренд на локальные модели
   · Формат: рилс
   · Источник: Hugging Face Papers — huggingface.co/papers
```

## Режим `digest` — дайджест топ-N новостей

**Назначение:** быстрый обзор самого важного за период (день / неделя), готовый к публикации или пересылке.

**Что берём.** Значимое по охвату и влиянию — включая хайповые новости и рыночные сдвиги (сделки, деньги, регуляторка, громкие заявления), а не только практически полезное. Мерило — «об этом будут говорить» или «это что-то сдвинет», а не «это пригодится в работе прямо сейчас».

**Поля каждой новости:**

```
N. Заголовок
   Суть: <1–2 строки — что случилось>
   Вывод: <по желанию — см. ниже>
   Ссылка: <URL>
```

### Вывод — по желанию

Вывод — это то, ради чего дайджест читают, а не пересказывают. Он есть там, где есть что сказать. Три вида:

- **Подколоть** — заметить иронию ситуации. «Продавать лопаты уже мало — хочется и самим копать».
- **Высказать мнение** — оценить: это важно, это пустое, это странно, и почему.
- **Связать** — две новости дня в одну мысль, которой нет ни в одной из них по отдельности.

Нечего сказать — пункт идёт без вывода, это нормально. Вывод, приклеенный к каждому пункту, превращается в шаблон («для X это значит…»), и его перестают читать.

Мнение и прогноз подаются как мнение, а не как факт: «похоже», «ставлю на то, что», «по-моему». Право утверждать — [`brand-voice/references/evidence-law.md`](../../brand-voice/references/evidence-law.md).

**Пример (2 новости):**

```
1. Microsoft и Anthropic в один день: агентам не доверяем
   Суть: глава Microsoft предложил считать любые модели «скомпрометированными» и ставить ручной стоп-кран; Anthropic отключила внутренние тесты агентов от интернета.
   Вывод: если даже они держат своих агентов на поводке — боту с доступом к твоей CRM поводок тоже не помешает.
   Ссылка: <URL> · <URL>

2. Meta открыла веса новой модели с коммерческой лицензией
   Суть: модель можно бесплатно использовать в коммерческих продуктах.
   Ссылка: <URL>
```

Во втором пункте вывода нет — новость говорит сама за себя.

## Режим `weekly` — структура недели (хэндофф в carousel-script)

**Назначение:** семь строк (Пн–Вс) с главной новостью каждого дня, готовых к передаче в скилл `carousel-script`.

**Важно: это хэндофф-структура для `carousel-script`** — каждая строка = один слайд карусели. Передавай весь блок как контент для скилла `carousel-script`, указав тему «Неделя в AI» и формат 7 слайдов.

**Поля каждой строки:**

```
День · Главная новость · 1 строка сути · Ссылка
```

**Пример (2 дня из 7):**

```
Пн · OpenAI анонсировала o3-mini для разработчиков · Лёгкая версия reasoning-модели доступна через API с 1 февраля · openai.com/news/o3-mini

Вт · Google DeepMind опубликовала AlphaFold 3 для некоммерческих задач · Предсказание структур белков и молекул — теперь бесплатно для науки · deepmind.google/discover/blog/alphafold3
```

**Полный шаблон недели (для заполнения):**

```
Пн · [новость] · [суть] · [ссылка]
Вт · [новость] · [суть] · [ссылка]
Ср · [новость] · [суть] · [ссылка]
Чт · [новость] · [суть] · [ссылка]
Пт · [новость] · [суть] · [ссылка]
Сб · [новость] · [суть] · [ссылка]
Вс · [новость] · [суть] · [ссылка]
```

## Режим `radar` — инструменты

**Назначение:** 3–5 свежих инструментов (репозитории, скиллы, плагины, MCP-серверы, модели) с пометкой, что из этого стоит потыкать руками. Как собирать и отбирать — [radar.md](radar.md).

**Поля каждого инструмента:**

```
N. Название — что это одной фразой
   Зачем: <что это даёт читателю, или вывод по правилам digest>
   ★ <число из API> · <ссылка>
   🔥 потыкать: <почему стоит> · ~<минут>      ← только у 0–2 пунктов
   ⚠️ <что смущает>                             ← только если есть сомнение
```

Последняя строка выдачи — всегда:

```
Проверено: GitHub ✓ · Trending ✓ · HN ✓ · Reddit ✓ · HF ✓ · Willison ✗ <причина>
```

**Пример (2 инструмента):**

```
1. iPhone-use — Codex управляет настоящим iPhone по USB
   Зачем: агент сам гоняет приложения и видит экран в реальном времени — проверка мобилки руками агента, а не твоими. README на китайском.
   ★ 2.8k · github.com/zhongerxin/iPhone-use
   🔥 потыкать: новый класс задач для кодового агента — телефон как инструмент · ~30 мин

2. ARTEX — автономная система пентеста на агентах
   Зачем: проект-победитель конкурса Baidu по атаке и защите агентов, код открыт.
   ★ 3.1k · github.com/mhtsec/ARTEX
   ⚠️ форков (5.5k) больше, чем звёзд, issues выключены — необычно, автор неизвестен

Проверено: GitHub ✓ · Trending ✓ · HN ✓ · Reddit ✓ · HF ✓ · Willison ✓
```
