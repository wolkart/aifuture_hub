# Режим `radar` — рецепт сбора инструментов

Радар ищет **сами инструменты** — репозитории, скиллы, плагины, MCP-серверы, модели, — а не статьи о них. Поэтому source-лесенка (Perplexity → WebSearch) здесь не работает: веб-поиск по «новым AI-инструментам» отдаёт обзоры СМИ. Источники берутся командами ниже — они отдают проекты с цифрами из API.

---

## 1. Сбор

Каждый источник — одна команда. Отказ одного не останавливает сбор: отметь его ✗ с причиной и иди дальше. `<дата-7>` — сегодня минус 7 дней (`ГГГГ-ММ-ДД`), `<epoch-24ч>` — unix-время сутки назад.

| Источник | Что ловит | Команда |
|---|---|---|
| **GitHub Search** | новые репозитории за неделю, которые быстро набирают звёзды | `gh search repos --created ">=<дата-7>" --stars ">=100" --sort stars --limit 30 --json fullName,description,stargazersCount,forksCount,openIssuesCount,createdAt,url` |
| **GitHub Search по темам** | то же в узких темах, где звёзд меньше | та же команда с `--topic <тема>` и `--stars ">=30"` — по разу на тему |
| **GitHub Trending** | старые проекты, которые вдруг выстрелили (поиск по дате создания их не видит) | открой `https://github.com/trending?since=daily`, бери «stars today» |
| **Show HN** | что авторы сами принесли на Hacker News | `curl -s "https://hn.algolia.com/api/v1/search?tags=show_hn&numericFilters=created_at_i%3E<epoch-24ч>,points%3E%3D30&hitsPerPage=30"` |
| **Reddit** | открытые модели, скиллы, харнесы | RSS `https://www.reddit.com/r/<саб>/top/.rss?t=day` для `LocalLLaMA`, `ClaudeAI`, `ClaudeCode`; передавай заголовок `User-Agent` |
| **Hugging Face** | трендовые модели | `curl -s "https://huggingface.co/api/models?sort=trendingScore&limit=20"` |
| **Simon Willison** | инструменты, которые кто-то уже попробовал руками | RSS `https://simonwillison.net/atom/everything/`, записи за 48 ч |

**Без `gh`** — тот же поиск через API: `curl -s "https://api.github.com/search/repositories?q=created:>=<дата-7>+stars:>=100&sort=stars&order=desc&per_page=30"` (без токена — 10 запросов в минуту).

**Что знать про площадки:**
- В `numericFilters` у HN знаки `>` и `>=` кодируются (`%3E`, `%3E%3D`), иначе API отвечает 400.
- JSON Reddit с серверных IP отдаёт 403 — поэтому RSS. На запросы подряд Reddit отвечает 429: между сабами пауза в пару секунд, при 429 один повтор, не вышло — ✗ 429.
- Trending — HTML-страница: читай её как текст, вёрстка меняется.

## 2. Темы

Дефолт — **инструменты для тех, кто строит с AI**:
- агенты и харнесы;
- скиллы и плагины для Claude Code, Codex и других кодовых агентов;
- MCP-серверы;
- открытые модели и их локальный запуск;
- ассистенты и боты по базе знаний (RAG).

Темы из вызова **заменяют** дефолт. Всё, что не попало в темы, отсеивается на шаге 3 — даже если звёзд много.

## 3. Отбор

1. **Отсей не по темам.**
2. **Отсей показанное**, если вызов передал файл «уже показывал» (см. §5).
3. **Проверь до 8 кандидатов** — открой репозиторий:
   - README есть и объясняет, что это и как запустить;
   - последний коммит свежий;
   - в issues и PR пишут разные люди;
   - кто автор: компания, известный разработчик, свежий аккаунт.
4. **Оставь 3–5.**

**Накрутка.** Звёзды покупают массово, и цифра сама по себе ничего не доказывает. Поводы присмотреться:
- тысячи звёзд при единицах форков;
- пачка однотипных репозиториев от одного свежего аккаунта;
- README из одного абзаца и ссылки на платный сервис.

Это **поводы проверить, а не приговор**: ноль issues часто значит, что issues выключены (так у многих репозиториев крупных компаний), а серия похожих проектов бывает настоящей. Подтвердилось — выкинь. Не уверен — оставь с пометкой ⚠️ и одной фразой, что смущает.

README только на китайском — не повод выкинуть, но отметь это в описании.

## 4. 🔥 потыкать

Пометка **0–2 пунктам** из выдачи. Нужны все три условия:
1. решает задачу, которую билдер или кодер реально делает, **или** открывает новый приём в работе с нейросетями;
2. ставится и запускается примерно за 30 минут;
3. проект живой, без ⚠️.

К пометке — одна строка: почему стоит и сколько времени займёт. Ни один не дотягивает — пометок нет, это нормальный день.

## 5. Файл «уже показывал»

Работает, только если вызов передал путь к файлу. Формат — строка на пункт: `ГГГГ-ММ-ДД URL`.
- **До отбора:** отсей кандидатов, чьи URL уже есть в файле.
- **После выдачи:** допиши показанные пункты, удали строки старше 30 дней.

Без пути шаг пропускается: ручной запуск показывает всё.

## 6. Выдача

Шаблон пункта и строка «Проверено» — в [output-modes.md](output-modes.md), раздел `radar`. Как писать вывод к пункту — там же, раздел `digest`: правила одни.

**Строка «Проверено» обязательна** — последней строкой выдачи. По ней видно, какие источники реально ответили сегодня.

**Нового нет** (всё отсеяно) — так и скажи одной строкой, без добивки слабыми пунктами. Если запуск идёт из планировщика, у которого есть свой протокол тишины (например, ответ `[SILENT]` у Hermes), — следуй ему.
