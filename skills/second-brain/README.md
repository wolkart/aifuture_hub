# second-brain — где применять

Второй мозг — папка заметок, которую ведут твои агенты: какие у тебя проекты, что это, где они
лежат, что главное по ним решено, что ты знаешь. Claude Code, Codex, OpenCode и Kimi читают её из
любой папки и сами дописывают туда то, что меняется редко: новый проект, решение и почему,
вышедший результат. Раскладывать руками ничего не нужно. Смотреть глазами — в Obsidian.

**Это не память проекта.** «Продолжаем, где остановились» — работа памяти проекта
([agent-memory](../agent-memory/)). Второй мозг — общая картина, как в голове.

## Что получится

| Что | Где | Кто пишет |
|---|---|---|
| Папка мозга: проекты, знания, контент, сырьё, дневник, архив | `~/second-brain` | агенты, сами |
| Правила для агентов: куда что класть, что не трогать | `~/second-brain/_CLAUDE.md` | при установке — агент; дальше ты, если хочешь |
| Каталог: агент читает его первым, чтобы не искать вслепую | `~/second-brain/index.md` | агенты |
| Обо мне: факты, на которые агенты опираются, когда пишут о тебе | `~/second-brain/About Me.md` | агент по твоим ответам |
| Правило «пиши в мозг» для всех агентов на компьютере | `~/.agents/AGENTS.md` | при установке — агент |
| История: любую правку можно откатить, даже через месяц | Git в папке мозга | фоновая задача, сама |

## Три уровня

| Уровень | Что даёт | Что нужно от тебя |
|---|---|---|
| 1. Базовый | всё из таблицы выше; история только на компьютере | фраза и ответы на несколько вопросов |
| 2. Синхронизация | мозг на GitHub в приватном репозитории, на нескольких компьютерах | аккаунт GitHub, один вход в браузере |
| 3. Сервер | копия у агента на сервере (Гермес, OpenClaw) — мозг с телефона через Telegram | агент на сервере уже стоит |

Мак и Windows. Уровни 2 и 3 можно добавить позже той же фразой.

## Поставить

Скажи агенту в любой программе:

```
Поставь второй мозг по этому скиллу: https://github.com/wolkart/aifuture_hub/tree/main/skills/second-brain
```

**Агенту:** скачай эту папку в `~/.agents/skills/second-brain` — команда в [SKILL.md](SKILL.md),
раздел «Установка», шаг 0 — и дальше иди по тем же шагам.

Агент спросит, есть ли у тебя уже волт, где хранить мозг, нужен ли GitHub и в каких программах
ты работаешь. Потом — несколько вопросов о тебе и твоих проектах. Если волт Obsidian уже есть,
агент перенесёт его в новую структуру: сам разложит, у тебя спросит только спорное, старый волт
не тронет.

Проверка — новое окно агента в любом проекте: «Что ты знаешь о моих проектах?»

## Просьбы в окне

- «запиши во второй мозг …»
- «разложи входящее» — то, что ты бросил в `raw/входящее/` не глядя;
- «проверь второй мозг» — раз в неделю: битые ссылки, противоречия, цифры без даты;
- «пересобери каталог»;
- «верни заметку такую-то, как было вчера»;
- «разбери конфликт во втором мозге» — если пришло уведомление.

## Чего не делает

- Не ищет по смыслу и не строит базу данных: мозг — обычные файлы Markdown, их читает любой агент.
- Не хранит ход работы — это память проекта.
- Не хранит пароли, ключи и токены.
- Не работает в облачной папке (iCloud, OneDrive, Яндекс.Диск, Dropbox) — облако ломает Git.

## Для продвинутых: вместе с obsidian-second-brain

Мозг совместим с тяжёлым скиллом obsidian-second-brain (48 команд `/obsidian-*`): те же имена
`_CLAUDE.md`, `About Me.md`, `index.md`, `.claude/CLAUDE.md`; `log.md` и `Logs/` он заведёт сам.

- Каталог не собирай через `/obsidian-init`: он перечисляет каждую заметку, и большой каталог
  съедает контекст в каждой сессии. Каталог — «пересобери каталог» (скрипт этого скилла).
- Его проверка заметок ругается на русское тире и на свойства контента. Выключить эти проверки:
  в `~/.config/obsidian-second-brain/.env` строка `AI_FIRST_SKIP_CHECKS=3,4,5`.
- Большие папки сырья исключи из его поиска: `.vault-config.json` в корне мозга —
  `{"exclude-dirs": ["cards"], "exclude-paths": ["archive", "raw/курсы"]}`.
