# Переезд старого волта во второй мозг

**Когда читать:** у человека уже есть волт Obsidian (или просто папка заметок), и он ставит
второй мозг. Переезд заменяет шаги 3–6 установки из `SKILL.md`; шаги 1–2 (вопросы, место не в
облаке) уже пройдены.

**Главное:** старый волт не трогаем — работаем с копией. Машина раскладывает, человек отвечает
только на спорное. Ни одна заметка не теряется: старый волт целиком остаётся в первом коммите с
меткой. Ссылки не рвутся: битые до и после считаются.

`<скилл>` — `~/.agents/skills/second-brain`, `<мозг>` — новая папка, `<старый>` — старый волт.
На Windows — `python` вместо `python3`, остальное — по [windows.md](windows.md).

## 1. Копия, не перенос

`<мозг>` должна не существовать или быть пустой. Копия без служебного мусора:

```bash
rsync -a --exclude .git --exclude .trash --exclude '.obsidian/workspace*.json' \
  --exclude '*.sync-conflict-*' --exclude .DS_Store "<старый>/" "<мозг>/"
```

```powershell
robocopy "<старый>" "<мозг>" /E /XD .git .trash /XF workspace*.json *.sync-conflict-* desktop.ini
```

- Старый волт был в Git — его история остаётся в старой папке как архив, у мозга начинается своя.
- Плагин Obsidian Git (`.obsidian/plugins/obsidian-git`) в копии выключи: убери `"obsidian-git"`
  из `.obsidian/community-plugins.json`. Его автосохранение и фоновая задача мозга вдвоём дали бы
  ложные конфликты.
- Дубли облака («Заметка (2).md») не выбрасывай при копировании — их решает опись.

## 2. Ключи — до Git

```bash
python3 -I <скилл>/scripts/migrate/scan_keys.py "<мозг>"
```

Каждое совпадение — глазами: обычно настоящих единицы, остальное — заглушки и куски ссылок.
Настоящий ключ — замени значение в копии на `<ключ убран>` и скажи человеку перевыпустить его:
ключ уже лежал в облаке. Повторяй, пока настоящих не останется. Только потом Git — из истории ключ
не вычистить.

## 3. Git: первый коммит — архив

```bash
cd "<мозг>"
git init -q -b main
git config core.quotepath false
git config core.precomposeunicode true      # только Мак
[ -n "$(git config user.email)" ] || { git config user.name "Второй мозг"; git config user.email "second-brain@$(hostname -s)"; }
git add -A && git commit -q -m "Старый волт как был"
git tag old-vault-<ГГГГ-ММ-ДД>
```

С этого момента всё, что «не берём», остаётся в этом коммите — его можно достать в любой момент.

## 4. Биография — до архива

Старые заметки о себе (профиль, позиционирование, «о себе», резюме) уедут в архив, а факты из них
нужны. Скопируй `<скилл>/templates/vault/About Me.md` в корень мозга и заполни из них: вечное
(путь, даты, стек), срезы с датой (цифры на свой день), «не утверждать» (цифры, которые в разных
заметках разошлись, и преувеличения). Покажи человеку и дополни вопросами шага 5 установки.

## 5. Опись

Дерево старого волта:

```bash
python3 -I <скилл>/scripts/migrate/inventory.py tree "<мозг>"
```

Открой по 2–3 заметки из каждой папки — решай по содержимому, а не по имени папки. Напиши
`<мозг>/_переезд/rules.json` по шести вопросам «куда класть» из `<скилл>/templates/vault/_CLAUDE.md`:
правило на папку, исключения — поштучно и **раньше** общего правила (решает первое совпадение).

```json
{"rules": [
  {"from": "0-Входящие/Разобрать позже.md", "to": "raw/входящее/", "why": "не разобрано", "ask": ""},
  {"from": "0-Входящие/", "to": "archive/Входящие/", "why": "старые входящие, никто не трогал с весны", "ask": ""},
  {"from": "1-Проекты/Сайт студии/", "to": "projects/Сайт студии/", "why": "проект в работе", "ask": ""},
  {"from": "Заметка (2).md", "to": null, "why": "дубль облака, совпадает с «Заметка.md»", "ask": ""},
  {"from": "Мысли о работе.md", "to": "journal/", "why": "личное", "ask": "это дневник или знание для wiki?"}
]}
```

- `"from"` с `/` на конце — папка, внутренняя структура сохраняется; без — файл или начало имени.
- `"to"` с `/` на конце — папка; без — точный новый путь (переименование); `null` — «не берём»:
  пустое, дубли облака, мусор. Не берём — не удаляем: всё есть в метке `old-vault-…`.
- Законченное и недействующее — `archive/`, а не «не берём».
- Не уверен — правило всё равно пиши, а в `"ask"` — вопрос человеку одной строкой.
- Проекты: папка проекта переезжает в `projects/<Проект>/`. Код и рабочие файлы проектов в волт
  не тянем — у них своя папка на компьютере, в мозге будет карточка.

```bash
python3 -I <скилл>/scripts/migrate/inventory.py build "<мозг>" "<мозг>/_переезд/rules.json"
```

Скрипт пишет `_переезд/Опись.md` и печатает счётчики. Человеку покажи итог по папкам и вопросы, а
не всю таблицу (таблица — в описи, если захочет посмотреть). Ответы → правь `rules.json` (снимай
`"ask"`) → `build` снова. Готово, когда: без правила — 0, коллизий — 0, вопросов — 0.
Одноимённые заметки — не ошибка: каталог сошлётся на них с путём; переименуй, только если
человек хочет.

## 6. Перенос

```bash
python3 -I <скилл>/scripts/migrate/move.py "<мозг>" "<мозг>/_переезд/plan.json" --dry
python3 -I <скилл>/scripts/migrate/move.py "<мозг>" "<мозг>/_переезд/plan.json"
```

Скрипт переносит файлы, правит пути в тексте заметок, базах и холстах, переписывает ссылки на
переименованные заметки, папки в настройках Obsidian, считает битые ссылки до и после.
«Занято» — два файла хотят в одно место: поправь правила, `build`, снова. Новые битые ссылки
должны быть 0; есть — посмотри каждую и почини.

## 7. Скелет мозга

Из `<скилл>/templates/vault/` скопируй то, чего в мозге ещё нет: `_CLAUDE.md`, `README.md`,
`index.md`, `.gitignore`, `.gitattributes`, `.claude/CLAUDE.md`, `templates/Карточка проекта.md`,
пустые папки. Существующее не затирай. `AGENTS.md` — ярлык на `_CLAUDE.md` (на Windows —
указатель). В `_CLAUDE.md` — путь вместо `<путь к мозгу>`. В `.obsidian/app.json` допиши
`"newFileLocation": "folder"` и `"newFileFolderPath": "raw/входящее"`, остальное там не трогай.

Карточки: на каждую папку в `projects/` — карточка `<Проект>.md` по шаблону, если её нет.
Потом шаг 6 установки — проекты на компьютере, которых в волте не было.

## 8. Пути к старому волту вне волта

Старый путь живёт в настройках скиллов (`.env`), инструкциях агентов, скриптах. Найди — и полный
путь, и форму с `~/`:

```bash
grep -rIlF --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=Library "<старый>" ~ 2>/dev/null
```

Список — человеку. Файлы памяти Claude Code (`~/.claude/projects/*/memory/`) — только с его
отдельного согласия. Потом:

```bash
python3 -I <скилл>/scripts/migrate/switch.py --old "<старый>" --new "<мозг>" --plan "<мозг>/_переезд/plan.json" --dry <файлы>
python3 -I <скилл>/scripts/migrate/switch.py --old "<старый>" --new "<мозг>" --plan "<мозг>/_переезд/plan.json" <файлы>
```

«Осталось старых» должно стать 0. Скрипт не печатает содержимое — в `.env` лежат ключи.

## 9. Каталог, карточки, коммит

```bash
python3 -I <скилл>/scripts/index.py "<мозг>"
python3 -I <скилл>/scripts/cards.py "<мозг>"
python3 -I <скилл>/scripts/links.py "<мозг>"
cd "<мозг>" && git add -A && git commit -q -m "Переезд: новая структура"
```

`_переезд/` остаётся в мозге как история: опись, правила, план.

## 10. Дальше

Шаги 7–10 установки из `SKILL.md`: правило для агентов, фоновое сохранение, Obsidian, проверка.
В Obsidian — «Open folder as vault» → новая папка; старый волт убрать из списка хранилищ. Уровни
2–3 — если человек хочет. Старый волт удалить или убрать из облака — решает человек, не раньше,
чем поработает с мозгом.

## Где спотыкаются

- **Решение по имени папки.** «Ресурсы» и «Проекты» пересекаются; открой заметки.
- **Облачные дубли «(2)».** Сравни с оригиналом: совпадают — `null`; различаются — оставь
  свежую, вторую в архив.
- **Пути в `.env`** скиллов и скриптов — шаг 8 ищет во всех текстовых файлах, не только в `.md`.
- **Регистр.** `bases` → `Bases` скрипт переименует сам в два шага: Мак регистр не различает.
