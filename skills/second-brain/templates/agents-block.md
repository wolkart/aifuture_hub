## Второй мозг

`<путь к мозгу>` — второй мозг человека: папка заметок с историей в Git (её можно смотреть в
Obsidian). Это общая картина, как его голова: какие есть проекты, что это, где лежат, что главное
по ним решено; знания, контент, факты о нём. Это не память проекта: продолжать работу помогают
память проекта и `PROGRESS.md`, их туда не дублируй.

- **Нужен контекст шире этой папки** — другой проект, факты о человеке, где что лежит — начни с
  `<путь к мозгу>/index.md`; правила — `<путь к мозгу>/_CLAUDE.md`.
- **Запиши туда сам, без просьбы, только медленное:** появился новый проект → карточка
  `projects/<Проект>/<Проект>.md` и строка в `index.md`; принято решение с «почему», которое
  меняет направление проекта → в его карточку, раздел «Главное решено», с датой; вышел результат
  (опубликовал, запустил, сдал) → в карточку, со ссылкой. Остальное — по правилу «куда класть»
  в `_CLAUDE.md`.
- **Не туда:** шаги, статус, «где остановились» — это `PROGRESS.md` и память проекта.
- Git в этой папке не трогай: изменения сохраняет фоновая задача. Подробности — скилл
  `second-brain` (`~/.agents/skills/second-brain/SKILL.md`).
