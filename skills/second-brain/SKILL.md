# second-brain — второй мозг для всех агентов

Второй мозг — одна папка заметок на человека: какие у него проекты, что это, где лежат, что
главное по ним решено; знания, контент, сырьё, дневник. Её читают все его агенты из любой папки
и сами дописывают туда медленное. Человек смотрит её в Obsidian, но раскладывать руками ему не нужно.

**Второй мозг — не память проекта.**

| | Второй мозг | Память проекта |
|---|---|---|
| Что помнит | общую картину: проекты, где лежат, что решено и почему, знания, факты о человеке | где остановились, ход работы |
| Где | одна папка на человека, по умолчанию `~/second-brain` | `PROGRESS.md` в проекте, память агента |
| Как меняется | редко: новый проект, решение, вышедший результат | каждый шаг |

## Устройство

```
~/second-brain/
├── _CLAUDE.md      правила для агентов — единственный источник; AGENTS.md — ярлык на него
├── README.md       объяснение для человека
├── index.md        каталог — агент читает его первым
├── About Me.md     факты о человеке: вечное, срезы с датой, что не утверждать
├── projects/  content/  wiki/  raw/входящее/  journal/  archive/  templates/  files/
└── .git            история: каждая правка откатывается

~/.agents/AGENTS.md     раздел «## Второй мозг» — правило для всех агентов на компьютере
~/.claude/CLAUDE.md     строка @~/.agents/AGENTS.md — то же правило для Claude Code
фоновая задача          раз в 5 минут сохраняет мозг в Git (launchd / Планировщик / cron)
```

Три уровня. Человек выбирает, всё дальше первого — по желанию и можно позже:

| Уровень | Что даёт | Где описан |
|---|---|---|
| 1. Базовый | папка, правила, каталог, правило для агентов, история на компьютере | ниже |
| 2. Синхронизация | приватный GitHub, мозг на нескольких устройствах | [references/sync.md](references/sync.md) |
| 3. Сервер | копия у агента на сервере (Гермес, OpenClaw) — мозг с телефона | [references/server.md](references/server.md) |

Шаблоны и скрипты — в этой папке скилла: `templates/vault/` (мозг), `templates/agents-block.md`
(раздел для агентов), `scripts/` (синхронизация, каталог, карточки, ссылки, переезд).
**На Windows** сначала прочитай [references/windows.md](references/windows.md): там отличия по
каждому шагу.

## Установка («поставь второй мозг»)

**0. Сам скилл** должен лежать в `~/.agents/skills/second-brain`: на этот путь ссылаются правила.
Нет его там — скачай только эту папку из хаба:

```bash
mkdir -p ~/.agents/skills
curl -fsSL https://codeload.github.com/wolkart/aifuture_hub/tar.gz/main | tar -xz -C ~/.agents/skills --strip-components=2 aifuture_hub-main/skills/second-brain
```

Ниже `<скилл>` — `~/.agents/skills/second-brain`, `<мозг>` — путь к папке мозга.

**1. Вопросы**, по одному:
- «У тебя уже есть волт Obsidian или второй мозг на другом компьютере?» Волт — дальше по
  [references/migration.md](references/migration.md). Мозг на GitHub — «Второй компьютер» ниже.
- «Где хранить мозг? По умолчанию — `~/second-brain`.»
- «Нужна синхронизация через GitHub — чтобы мозг был на нескольких устройствах или у агента на
  сервере?» Да — после установки уровни 2–3.
- «В каких программах работаешь: Claude Code, Codex, OpenCode, Kimi?»

**2. Место не в облаке.** Облако ломает Git: плодит копии «(2)», портит имена. Не годится путь,
в котором есть `Library/Mobile Documents`, `Library/CloudStorage`, `iCloud`, `OneDrive`,
`Dropbox`, `Yandex.Disk`; на Маке ещё `~/Documents` и `~/Desktop` (их может забирать iCloud).
Попало — объясни одной фразой и предложи домашнюю папку. Папка уже есть и не пустая — не копируй
поверх: это старый волт (переезд) или мозг (повторная установка, ниже).

**3. Шаблон.**

```bash
mkdir -p <мозг> && cp -R <скилл>/templates/vault/. <мозг>/
cd <мозг> && ln -s _CLAUDE.md AGENTS.md
```

В `_CLAUDE.md` замени `<путь к мозгу>` на путь к мозгу (`~/second-brain` подойдёт: скрипты
раскрывают `~` сами), в свойствах `About Me.md` и `index.md` `<ГГГГ-ММ-ДД>` — на сегодняшнюю дату.

**4. Git.**

```bash
cd <мозг>
git init -q -b main
git config core.quotepath false
git config core.precomposeunicode true      # только Мак: «й» и «ё» в именах
# имени в Git нет — подписываем мозг «Второй мозг», иначе Мак подставит системное имя человека
[ -n "$(git config user.email)" ] || { git config user.name "Второй мозг"; git config user.email "second-brain@$(hostname -s)"; }
git add -A && git commit -q -m "Второй мозг создан"
```

**5. Обо мне.** Спроси по одному, ответы — в `About Me.md` по трём разделам:
1. Кто ты и чем занимаешься?
2. Твой путь: откуда пришёл, какие события были главными — с годами?
3. Какими инструментами и технологиями пользуешься?
4. На чём зарабатываешь или хочешь зарабатывать?
5. Какие цели на ближайшие месяцы?
6. Как с тобой говорить: на «ты» или «вы», коротко или подробно?
7. Что о тебе нельзя утверждать — цифры, которые разошлись, преувеличения?

Цифра, которая меняется (подписчики, клиенты, стаж), идёт в «Срезы с датой» с датой: «на 2026-11:
…». Без даты — не пиши. Человек не хочет отвечать — оставь раздел с заглушкой.

**6. Проекты.** Спроси: «Какие у тебя сейчас проекты и где они лежат?» Предложи найти папки
проектов самому:

```bash
find ~ -maxdepth 4 \( -name Library -o -name node_modules -o \( -name '.*' -not -name .git \) \) -prune \
  -o -name .git -type d -print 2>/dev/null | sed 's#/\.git$##'
```

Покажи список без самого мозга, человек вычеркнет лишнее. На каждый проект — карточка
`projects/<Проект>/<Проект>.md` по шаблону `<мозг>/templates/Карточка проекта.md`:
- `<Проект>` — название по-человечески: заголовок README проекта или слова человека, не имя папки;
- `{{date:YYYY-MM-DD}}`, `{{title}}` и все `<…>` замени; чего не знаешь — убери строку;
- «Что это» — из README проекта или со слов человека;
- «Где живёт» — путь и `git -C <папка> remote get-url origin`; нет origin — «git только на компьютере»;
- «Где смотреть статус» — `PROGRESS.md`, если есть, иначе история Git проекта;
- «Главное решено» — пока «—»: решения агенты допишут по ходу работы.

Сами проекты не переносятся: карточка — указатель. Потом каталог, карточки и коммит (установка —
исключение из правила «агент не делает git в мозге»):

```bash
python3 -I <скилл>/scripts/index.py <мозг>
python3 -I <скилл>/scripts/cards.py <мозг>
git -C <мозг> add -A && git -C <мозг> commit -q -m "Обо мне и проекты"
```

Python нет — строки в `index.md` допиши сам по образцу.

**7. Правило для агентов.** Текст `<скилл>/templates/agents-block.md`, в нём `<путь к мозгу>` →
путь (с `~/`, если мозг в домашней папке) — в общий файл агентов `~/.agents/AGENTS.md`: файла нет —
создай; раздел `## Второй мозг` есть — замени; нет — допиши в конец. Потом — программы из ответа
про программы (шаг 1):
- **Claude Code:** в `~/.claude/CLAUDE.md` строка `@~/.agents/AGENTS.md`, если её нет (файла нет —
  создай). В `~/.agents/AGENTS.md` есть раздел `## Память` — сразу под этой строкой допиши: «Раздел
  „Память“ оттуда к Claude Code не относится: у него своя память».
- **Kimi Code** читает `~/.agents/AGENTS.md` сам.
- **Codex, OpenCode** — через ярлык на общий файл:

  ```bash
  mkdir -p ~/.codex ~/.config/opencode
  ln -s ~/.agents/AGENTS.md ~/.codex/AGENTS.md              # Codex
  ln -s ~/.agents/AGENTS.md ~/.config/opencode/AGENTS.md    # OpenCode
  ```

  Ярлык уже есть — ничего не делай. На его месте обычный файл с текстом — не затирай: покажи
  человеку и дальше по шагу 3 «Установки» скилла agent-memory (там же Windows):
  https://github.com/wolkart/aifuture_hub/blob/main/skills/agent-memory/SKILL.md. Проверка Codex:
  `codex debug prompt-input < /dev/null | grep "## Второй мозг"`.

**8. Фоновое сохранение.** Мак: `bash <скилл>/scripts/install-sync.sh <мозг>`. Windows — по
[references/windows.md](references/windows.md). Linux — строка cron, как в
[references/server.md](references/server.md), шаг 4. Пока GitHub не подключён, задача только
сохраняет историю на компьютере.

**9. Obsidian** (по желанию). Нет программы — предложи: `brew install --cask obsidian` /
`winget install Obsidian.Obsidian`. Дальше: «Open folder as vault» → папка мозга.

**10. Проверка.** Новое окно агента в любом другом проекте: «Что ты знаешь о моих проектах?» —
ответ должен прийти из карточек мозга. Через 5 минут фоновая задача отработала дважды (при
загрузке и по расписанию): `launchctl print gui/$(id -u)/local.second-brain.sync | grep -E 'runs|last exit code'`
— `runs` не меньше 2, код 0; в `~/Library/Logs/second-brain-sync.log` — строки «ок». Windows — по
[references/windows.md](references/windows.md).

В конце скажи человеку, что поставлено и где, и дай три фразы: «запиши во второй мозг …»,
«разложи входящее», «проверь второй мозг». Предложи уровни 2–3, если он их хотел.

**Второй компьютер.** Мозг уже на GitHub: шаги 0, 2, потом шаги 1–2 из
[references/sync.md](references/sync.md) — `gh`, вход и `gh auth setup-git`, даже если `gh` уже
стоит: без него фоновая задача не сможет отправлять. Потом `gh repo clone <репозиторий> <мозг>`, в
папке мозга — `git config core.quotepath false` и строка имени из шага 4, дальше шаги 7–10.
Шаблон, «Обо мне» и проекты не нужны — они в репозитории.

**Повторная установка** на живом мозге ничего в нём не затирает: `_CLAUDE.md` и `README.md` —
уже вещи человека. Шаблон скилла новее — покажи разницу и перенеси то, что человек одобрит.
Раздел в `~/.agents/AGENTS.md`, строку Claude Code и фоновую задачу обнови молча.

## Просьбы человека

- **«Запиши во второй мозг …»** — по правилу «куда класть» из `_CLAUDE.md` мозга.
- **«Разложи входящее»** — каждую заметку из `raw/входящее/` по тому же правилу. Спорное — одной
  строкой человеку. Новая заметка — строка в `index.md`.
- **«Проверь второй мозг»** (раз в неделю) — `python3 -I <скилл>/scripts/links.py <мозг>` (битые
  ссылки); заметки, на которые никто не ссылается; противоречия между заметками; меняющиеся цифры
  без даты; папки проектов с `.git` без карточки. Отчёт списком, правки — с согласия.
- **«Пересобери каталог»** — `index.py` и `cards.py`, как в шаге 6.
- **«Разбери конфликт»** — фоновая задача остановилась: изменения с двух устройств пересеклись.
  В папке мозга: `git fetch origin`, `git rebase origin/main`. В каждом спорном файле сохрани обе
  версии текста — ничего не выбрасывай; непонятно, что оставить, — покажи человеку. Потом
  `git add -A`, `git -c core.editor=true rebase --continue` (без редактора: терминала у агента
  нет), `git push origin main` и удали отметку `.git/second-brain-conflict` — задача снова начнёт
  отправлять.
- **«Верни заметку как было вчера»** — `git log --format='%h %ad %s' --date=format:'%F %R' -- "<файл>"`,
  выбери версию на нужное время, `git checkout <хеш> -- "<файл>"`, коммит «Вернул <файл> на <дата>».

Конфликт и откат — единственные случаи, когда агент сам делает `git` в мозге. В остальное время
только пишет файлы: сохраняет фоновая задача.

## Где спотыкаются

- **Облако.** Мозг в iCloud, OneDrive, Яндекс.Диске или Dropbox ломает Git. Держать вне облака.
- **Ключи.** В заметки не попадают никогда: из истории Git их не вычистить.
- **Плагин Obsidian Git** не включать: фоновая задача уже делает его работу, вдвоём они создают
  ложные конфликты.
- **Мак во сне** не сохраняет; после пробуждения всё уйдёт в течение 5 минут.
- **Модель может не открыть мозг сама.** Правило в окно кладёт программа, а каталог модель
  открывает по правилу. Страховка — фраза человека «посмотри во втором мозге».
