# Пороги и параметры

Дефолты выбраны под разговорную запись с приличным микрофоном. Все крутятся флагами CLI.

## Тишина (`detect_silence.py`)

| Параметр | Дефолт | Когда крутить |
|---|---|---|
| `--noise-db` | −35 dB | Шумный фон (улица, вентилятор) → −30; студийная тишина → −40 |
| `--min-dur` | 0.8 с | Быстрая плотная речь → 0.5–0.6; медленная подача → 1.0 |
| `--pad` | 0.15 с | Паддинг внутрь интервала: сколько «дыхания» оставить вокруг речи. Речь обрезается на стыках → увеличить до 0.2–0.25 |
| `--min-cut` | 0.4 с | Резы короче этого не делаем (дёрганый монтаж хуже паузы) |

**Вдохи и звук камеры.** `silencedetect` смотрит на пики: вдох перед фразой на встроенном микрофоне камеры (−40 dB RMS) проходит порог −35 dB как «речь», и кусок стартует на 0.3–0.6 с раньше слова. На отдельной петличке с шумодавом паузы — цифровой ноль, границы речи там видны до 10 мс. Поэтому тишину ищи по чистому звуку, а не по камере.

## Синхрон (`sync_offset.py`)

- `confidence` — peak-to-sidelobe: насколько пик корреляции уникален (не зависит от разности тембров микрофонов; чистая блокировка даёт ~0.9 даже когда камера-встройка и OBS-микрофон звучат по-разному).
- `confidence < 0.5` — смещению не верить: нет общего сигнала (разные помещения, сильный шум). Просить хлопок в начале записи или ручное смещение (`--offset` в `silence_cut.py` / ручная правка `sync.offset_s` в cut-list).
- `--max-seconds 600` — корреляция по первым 10 минутам; для очень длинных записей достаточно.

## Кадры скринкаста (`extract_frames.py`)

- `edge = 0.2 с` — отступ от границ тихого участка (на границах бывает смаз перехода).
- Участок ≤ 0.4 с → один кадр из середины, длиннее → 3 кадра (начало/середина/конец).

## Транскрипт (`transcribe.py`)

- Модели по умолчанию: `mlx-community/whisper-large-v3-turbo` (Apple Silicon) / `large-v3` (faster-whisper). Слабое железо → `--model small` (хуже пословные таймкоды, но быстрее).

## Взгляд (`gaze_trim.py`, только macOS — Apple Vision)

| Параметр | Дефолт | Когда крутить |
|---|---|---|
| `--down-delta` | 3.0° | Насколько ниже позы «в камеру» — уже «смотрит в сценарий». Поза «в камеру» = 20-й перцентиль наклона головы в серединах кусков (во время речи голова гуляет на ±10°, медиана завышена). Строгий порог почти ничего не стоит: срезаются только кадры без речи. Режет лишнее у спикера, который говорит с опущенной головой → 5–6° |
| `--guard` | 0.03 с | Запас до первого и после последнего звука — дальше речь не режется ни при каком взгляде |
| `--speech-db` | −38 dB RMS | Порог «здесь речь» внутри куска, по чистому звуку. Шумная дорожка без шумодава → −32 |

Знак наклона: pitch > 0 — голова опущена. Лицо не найдено — край куска не трогается.

## Подгонка слов (`snap_words.py`)

| Параметр | Дефолт | Смысл |
|---|---|---|
| `--quiet` | −48 dB | Первые 40 мс слова тише этого — слово стоит в тишине, его надо сдвинуть |
| `--loud` | −38 dB | Новое начало — первый 10-мс кадр громче этого (минус 20 мс на атаку) |

Нужна только для субтитров и графики, привязанных к словам: для резки точности Whisper хватает.
