# Теги, главы, текст на превью

## Теги — гигиена, а не рычаг

Ориентир **20–40 тегов**, от общего к частному: сначала широкие («ии»,
«нейросети», «автоматизация»), потом узкие («claude code бесплатно»,
«free claude code», конкретные имена моделей).

Число взято из медианы Сараева — 37 тегов на ролик, теги проставлены у 299
роликов из 300.

**Но прямо скажи автору: это гигиена, а не рычаг роста.** У Нейта Хёрка теги
стоят лишь у 43 роликов из 300 — при вдвое большей аудитории (924k против
492k). Ставим потому, что бесплатно и не мешает, а не потому, что растит.

Практический вывод: не трать на теги больше двух минут. Если их нет вообще
(случай канала автора — 0 из 7 роликов), проставить стоит; вылизывать — нет.

## Хэштеги — не мерили, так и говори

Хэштеги в замеры **не входили ни разу**. Ни по одному каналу нет сравнения
роликов с ними и без. Предлагаешь набор — скажи прямо, что это подбор по теме,
а не вывод из данных, иначе догадка поедет дальше с интонацией замера.

Что известно по механике: пишутся **один раз, в самом низу описания**, YouTube
сам поднимает **первые три** и показывает их над заголовком. Поэтому порядок
имеет значение, а вручную дублировать их в первой строке нельзя — они съедят
125 символов поискового сниппета.

Ориентир при подборе: сначала бери те, что уже стоят на прошлых роликах автора
(конвенция канала), потом добавляй тему конкретного ролика. Единственное
наблюдение под рукой: у Бычкова (171k, та же ниша) хэштегов нет вообще ни
одного — значит, это точно не рычаг.

## Главы

**Первая метка обязательно `00:00`.** Это не стилистика, а требование YouTube:
без метки на нуле он создаёт безымянную заглушку `<Untitled Chapter 1>`, и
первый кусок ролика остаётся без названия в навигации.

Реальный случай: у автора в ролике `Claude Code бесплатно и как собрать на нём
первое приложение` главы начинались с `00:19` — YouTube дописал заглушку сам,
первые 19 секунд остались безымянными.

Остальные требования площадки: минимум 3 главы, каждая не короче 10 секунд,
метки по возрастанию.

**Что говорит замер.** У Сараева ролики с главами дают 1.2 против 0.64 без них
(197 роликов против 103) — разрыв почти двукратный. У Нейта разницы нет:
0.97 против 1.0. Поэтому подавай главы как «дёшево и вероятно полезно», а не
как закон площадки. Скорее всего они не гонят просмотры сами по себе, а
маркируют ролики, в которые автор вложился целиком.

Названия глав пишутся по закону текста: не «Введение», а что человек там
получит. Исключение — первая метка `00:00`, где «Вступление» допустимо.

**Главы снимаются с готового ролика, а не выводятся из сценария.** Даже когда
сценарий писался этим же скиллом и лежит рядом, порядок блоков в нём — не
порядок блоков в видео: автор импровизирует, меняет местами, что-то вырезает
на монтаже. Главы, собранные по сценарию, разъедутся с картинкой, и зритель
попадёт не туда, куда ткнул.

Нет доступа к смонтированному ролику — **не выдумывай последовательность**.
Отдай автору способ: пролистать таймлайн и отметить моменты, где меняется тема
(на двадцать минут их обычно 12–18), прислать список с временами — а ты
причешешь названия. Это тридцать секунд его работы против главы, которая врёт.

## Текст на превью

Замер: Vibecoder School, 47 превью из 47 распознаны Apple Vision
(режим `thumbs` в `youtube-analytics`).

| Признак на превью | С признаком / без | Роликов |
|---|---|---|
| **«бесплатно»** | **3.75 / 0.96** | 6 |
| имя платного инструмента | 1.38 / 0.89 | 19 |
| цифра или сумма | 1.19 / 0.72 | 31 |
| текст ≤4 слов | **0.89 / 1.27** | 14 |

**Главное: на превью работает та же ось, что в тайтле** — цена, имя
инструмента, конкретика. Превью и тайтл не два разных жанра, а одно сообщение
в двух местах. Собирай их вместе, а не по отдельности.

**Расхожий совет «пиши 2–4 слова на превью» опровергнут замером:** короткие
дали 0.89 против 1.27 у длинных. Не сокращай текст ради краткости — сокращай,
если слова не несут ни цены, ни имени, ни цифры.

Выдавай **2–3 варианта текста** и указывай, какой сигнал в каждом:

```
1. БЕСПЛАТНО НАВСЕГДА          ← цена (сильнейший сигнал)
2. CLAUDE CODE ЗА 0 ₽          ← цена + имя инструмента
3. ПЕРЕСТАНЬ ПЛАТИТЬ ЗА API    ← запрет + цена
```

**Чего скилл не делает: советов по композиции.** Лицо, эмоция, контраст,
стрелки, кружки — этого мы не мерили, а CTR публичный API не отдаёт. Любой
совет здесь был бы пересказом чужих статей, выданным за твои данные. Спросят —
скажи прямо, что данных нет, и предложи вернуться к вопросу, когда появится
OAuth-ветка с настоящим CTR.
