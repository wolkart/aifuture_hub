# youtube-meta — где применять

Скилл пишет **мету под длинное горизонтальное YouTube-видео**: два тайтла на
тест, описание по шаблону автора, теги, каркас глав и текст на превью.

Главное отличие от «напиши мне тайтл по SEO-канонам»: скилл стоит на **замерах
пяти каналов ниши** (947 роликов, снято `youtube-analytics`), и часть расхожих
советов на этих данных не подтвердилась.

## Когда срабатывает

- «Напиши тайтл для ролика», «сделай описание под видео», «собери мету»,
  «оформи ролик на ютуб», «проверь мету моего ролика», «какой тайтл лучше»,
  «сделай как у него, но под меня», «перенеси этот ролик под мою тему».

НЕ пишет сценарий и вступление, НЕ анализирует каналы (это `youtube-analytics`),
НЕ про Shorts — у коротких механика ленты, там работает `reels-script`.

## Три режима

- **`СОБРАТЬ`** (дефолт) — тема ролика → готовая мета: два тайтла, описание,
  теги, главы, текст на превью.
- **`ПРОВЕРИТЬ`** — аудит опубликованного ролика или черновика: список поломок
  с приоритетом, что чинится за минуту и даёт эффект.
- **`ПЕРЕНОС`** — по ссылке на чужой ролик собирает свою версию под свою тему,
  с проверкой годности референса на входе.

## На чём стоит

Каждая рекомендация имеет степень уверенности:

| Уровень | Что туда попало |
|---|---|
| Подтверждено на 4 каналах из 4 | слово «бесплатно», формат курса или гайда |
| Подтверждено на 3 из 4 | имя инструмента, цифра в тайтле |
| Стоп-лист | CAPS (у одного канала **вредит**), скобки, отрицание лидера, тег года |

Скилл сам стоп-лист не предлагает; попросят — поставит, но скажет, чем рискован.

## Правила ленты сюда не переносятся

В `copy-law` и `reels-script` записано, что имя инструмента в хуке проигрывает
выгоде в 10–30 раз. **На YouTube наоборот** — имя в тайтле работает, потому что
это поисковый запрос. Лента показывает непрошеное, YouTube поисковый.

Скилл держит эту развязку у себя и не тянет запрет из ленты.

## Чего скилл не делает

- **Не советует по композиции превью** (лицо, эмоция, контраст) — CTR публичный
  API не отдаёт, композицию не мерили. Только текст на превью.
- **Не публикует** — `videos.update` требует OAuth с правом записи.
- **Не выдумывает объёмы поисковых запросов** — таких данных в API нет.

## Связка с `youtube-analytics`

Замеры считает аналитика, применяет мета. Числа в `references` датированы;
устарели — прогон `youtube-analytics` (`scout` → `patterns` → `thumbs`),
а не правка руками.

## Примеры вызова

```
собери мету под ролик про то, как поднять Claude Code бесплатно
```

```
проверь мету моего последнего ролика — что чинить
```

```
перенеси вот этот ролик под мою тему: https://youtube.com/watch?v=...
```
