# plan.json и PLAN.md

Читать на стадии 3, перед тем как писать план.

План — договор между тобой и скриптами. Автор его не читает: он смотрит
`PLAN.md`, которую собирает `plan_md.py`. Всё привязано **к словам**, а не к
секундам: пересобрал черновик — секунды съехали, слова остались, план переносится.

## Якорь

Число — секунды ролика. Объект — слово расшифровки:

```json
{"word": "сервер", "n": 2, "shift": -0.1, "edge": "start"}
```

`n` — какое по счёту вхождение (с 1), `shift` — сдвиг в секундах, `edge` —
`start` или `end` слова. Строка `"сервер"` — то же, что `{"word": "сервер"}`.
Слово сравнивается без регистра и пунктуации, `ё` = `е`, дефис внутри
сохраняется («телеграм-канал»). Нет слова — `plan_md.py` скажет, сколько
вхождений нашлось.

## Поля

Комментарии `//` — пояснения образца, в настоящем файле их нет.

```json
{
  "version": 1,
  "mode": "full",
  "label": "по слову, лайм",              // метка в имени финала и README
  "accent": "лайм",                       // имя из настроек — на этот ролик
  "captions": "по_слову",                 // строки | по_слову — на этот ролик
  "accent_words": ["канал", "бесплатно"], // ударные слова субтитров, 10–20 на 40 с
  "punch_words": ["бесплатно", "нужен"],  // «вжух» наезда, 3–6 на ролик
  "zoom": true, "music": true,
  "behind_text": [],                      // опция «текст за головой», см. scripts/behind.py
  "items": []
}
```

### items

**Б-ролл или ассет** — вставка поверх спикера:

```json
{"kind": "broll", "from": {"word": "одну", "shift": -0.02}, "to": {"word": "в", "shift": -0.02},
 "asset": "github-install",            // id из index.json библиотеки
 "file": "github.mp4",                 // …или файл: абсолютный, рядом с исходниками, в папках б-роллов
 "in": 19.8,                           // секунда источника, с которой начать
 "rate": 2.2,                          // скорость (1 — как есть)
 "layout": "half",                     // full — весь экран; half — верх, спикер уезжает вниз
 "pos": "50% 45%",                     // object-position: что из кадра оставить в 9:16
 "note": "выделение команды → Copied!"}  // что видно — для таблицы и для проверки
```

`in` бери из событий описи (`index.json`, поле `events`): «объект виден целиком
на 19,8 с». Окно источника = `in` … `in + длина × rate`; оно не должно задевать
`private` и, по возможности, `transitions` — `plan_md.py` проверит.

**Карточка** — когда показать нечего, а мысль важная:

```json
{"kind": "card", "template": "tiles", "from": "Без", "to": {"word": "Берешь", "shift": -0.08},
 "slots": {"items": [{"icon": "</>", "label": "код", "crossed": true, "at": "Без"},
                     {"icon": "0 ₽", "label": "бесплатно", "ok": true, "at": "бесплатно"}]}}
```

Шаблоны и слоты — `cards.md`. `"to": 999` — до конца ролика.

**Нет ассета** — строка в плане, а не выдумка:

```json
{"kind": "missing", "at": "расписанию", "want": "табло часов публикаций"}
```

В таблице появится «нет ассета → карточка или motion-assets». Автор решит:
карточка сейчас или сцена в библиотеку на будущее.

## PLAN.md (что видит автор)

```markdown
# План: C0001 — v1 (full)

Длина 36.6 с · субтитры: по слову · акцент: лайм · наезды: да · музыка: да · текст за головой: нет
Под вставками 24.3 с из 36.6; б-роллов 24, карточек 2

| время | слово | что появляется | раскладка | наезд |
|---|---|---|---|---|
| 0.00–1.44 | «Сейчас» | спикер | — | наезд 1.00→1.05 |
| 1.44–2.68 | «одну» | б-ролл github.mp4 @19.8 ×2.2 — выделение команды → Copied! | half | наезд 1.00→1.05 |
| 5.00–7.64 | «Без» | карточка «плитки» | карточка | вжух «бесплатно» 1.15→1.27 |

## Предупреждения
- ⚠ #7 9.92–10.38: вставка 0.46 с — вне ориентира 0.5–1.8 с

## Нет ассета
- 24.10 с «расписанию»: табло часов публикаций → карточка или motion-assets
```

Первые строки таблицы — это хук: по ним видно, начинается ли ролик с результата.
