# plan.json и PLAN.md

Читать на стадии 3, перед тем как писать план.

План — договор между тобой и скриптами. Автор его не читает: он смотрит
`PLAN.md`, которую собирает `plan_md.py`. Всё привязано **к словам**, а не к
секундам: пересобрал черновик — секунды съехали, слова остались, план переносится.

## Якорь

Число — секунды ролика. Объект — слово расшифровки:

```json
{"word": "сервер", "n": 2, "shift": -0.1, "edge": "start"}
```

`n` — какое по счёту вхождение (с 1), `shift` — сдвиг в секундах, `edge` —
`start` или `end` слова. Строка `"сервер"` — то же, что `{"word": "сервер"}`.
Слово сравнивается без регистра и пунктуации, `ё` = `е`, дефис внутри
сохраняется («телеграм-канал»). Нет слова — `plan_md.py` скажет, сколько
вхождений нашлось.

## Поля

Комментарии `//` — пояснения образца, в настоящем файле их нет.

```json
{
  "version": 1,
  "mode": "full",
  "label": "по слову, лайм",              // метка в имени финала
  "accent": "лайм",                       // имя из настроек — на этот ролик
  "captions": "по_слову",                 // строки | по_слову — на этот ролик
  "cta": "ссылка",                        // код | ссылка — на этот ролик (иначе cta.тип из настроек)
  "accent_words": ["канал", "бесплатно"], // ударные слова субтитров, 10–20 на 40 с
  "captions_from": "субтитры",            // до этого слова субтитров нет (ролик «голый»)
  "captions_keys": [                       // по ходу ролика: место и стиль меняются на слове
    {"at": "субтитры", "top": 950},        //   на лице
    {"at": "ниже", "top": 1385, "slide": 0.5},  // строка не прыгает, а едет за рукой 0,5 с
    {"at": "Тоже", "style": "капс", "enter": "right"},  // смахнул: строка влетает с края
    {"at": 0, "style": "заголовок", "top": 360, "px": 150}],  // начало ролика: слова друг над другом,
                                           //   нижнее крупнее градиентом, без обводки, в ширину кадра
  "captions_insert": [{"at": {"word": "еще", "edge": "end", "shift": 0.12}, "text": "новый стиль", "dur": 0.5}],
                                           // текст, которого не говорили (показать новый стиль на взмахе)
  "captions_replace": {"Аху...": "АХУ***[[!]]"},  // текст на экране вместо сказанного; [[…]] — огненный цвет
  "captions_hide": [{"from": "Переходи", "to": "end"}],  // окна без субтитров (концовка)
  "punch_words": ["ИИ", {"word": "наезд", "add": 0.35, "back": 0.1}],  // вжух; сила и отъезд «вжух-вжух»
  "sfx": [{"at": "ниже", "sound": "down", "db": -9, "shift": -0.14}],  // звуки: sfx.py, каталог в шапке
  "music_levels": [                        // громкость музыки по словам, dB к обычному уровню
    {"at": 0, "db": -10}, {"at": "Музыку", "db": 8, "ramp": 0.3}, {"at": "громкость", "db": 0, "ramp": 0.8}],
  "punch_words": ["бесплатно", "нужен"],  // «вжух» наезда, 3–6 на ролик
  "zoom": true, "music": true,
  "behind_text": [],                      // опция «текст за головой», см. scripts/behind.py
  "items": []
}
```

### items

**Б-ролл или ассет** — вставка поверх спикера:

```json
{"kind": "broll", "from": {"word": "одну", "shift": -0.02}, "to": {"word": "в", "shift": -0.02},
 "asset": "github-install",            // id из index.json библиотеки
 "file": "github.mp4",                 // …или файл: абсолютный, рядом с исходниками, в папках б-роллов
 "in": 19.8,                           // секунда источника, с которой начать
 "rate": 2.2,                          // скорость (1 — как есть)
 "layout": "half",                     // full — весь экран; half — верх, спикер уезжает вниз
 "pos": "50% 45%",                     // object-position: что из кадра оставить в 9:16
 "note": "выделение команды → Copied!"}  // что видно — для таблицы и для проверки
```

`"film_roll": [{"from": <якорь>, "dur": 0.75, "cycles": 4}]` — кадр-лента: кадр уезжает вверх,
за ним едет тот же, всё быстрее, и встаёт на место без шва («смонтировал», «кадр за кадром»);
в паре с карточкой `filmstrip` (плёнка по бокам со словом) и звуком `swish` на каждый проход.

`"enter": "down"` у вставки half — половина не появляется кадром, а съезжает сверху за 0,4 с
(жест «стянуть шторку»), спикер уезжает вниз вместе с ней.

`in` бери из событий описи (`index.json`, поле `events`): «объект виден целиком
на 19,8 с». Окно источника = `in` … `in + длина × rate`; оно не должно задевать
`private` и, по возможности, `transitions` — `plan_md.py` проверит.

**Карточка** — когда показать нечего, а мысль важная:

```json
{"kind": "card", "template": "tiles", "from": "Без", "to": {"word": "Берешь", "shift": -0.08},
 "slots": {"items": [{"icon": "</>", "label": "код", "crossed": true, "at": "Без"},
                     {"icon": "0 ₽", "label": "бесплатно", "ok": true, "at": "бесплатно"}]}}
```

Шаблоны и слоты — `cards.md`. `"to": 999` — до конца ролика.

**Концовка-ссылка** — когда CTA ролика `ссылка`: 3D-концовка с профилем из библиотеки
(`library.py find концовка`), последним пунктом, на весь экран, до конца ролика:

```json
{"kind": "broll", "asset": "end-ig-pop", "from": {"word": "Ссылка", "shift": -0.1}, "to": 999,
 "in": 0.0, "layout": "full", "note": "профиль, ссылка выходит плашкой, тап"}
```

Кодовое слово (карточка `cta`) и концовка-ссылка в одном ролике — ✗ в PLAN.md: это два
разных призыва. Ориентир длины вставки к концовке не применяется — она держит кадр до конца.

**Нет ассета** — строка в плане, а не выдумка:

```json
{"kind": "missing", "at": "расписанию", "want": "табло часов публикаций"}
```

В таблице появится «нет ассета → карточка или motion-assets». Автор решит:
карточка сейчас или сцена в библиотеку на будущее.

### Монтаж «по команде» — когда в кадре говорят, что сделать

Ролик, где автор командует монтажом в кадре («нужны субтитры», «ниже», «другой стиль»,
«музыку», «убери фон», «текст за мной»), собирается теми же ключами, привязанными к
словам-командам: `captions_from` + `captions_keys` (появились, переехали, сменили стиль),
`music_levels` (тихо → громко → под голос), окно `behind_text` с `"fade_in": 0.35`
(«убери фон» — комната растворяется в подложку) и фразой за головой на «текст».
Жест рукой `/reel` не видит — эффект встаёт на слово, поэтому `slide` ≈ длина жеста.
У каждого жеста-эффекта свой звук (`sfx`): опустил — `down`, смахнул — `swish`, стянул
графику — `down` + `impact` на приземлении, вжух — `whoosh`, печать — `type`, наклейка —
`pop`, тап — `tap`. Строка за головой печатается по буквам: `"type": 0.6` у строки; своя
высота строки — `"top"`. Наклейка на кадр (заклеить рот на мате) — карточка `sticker`.

Сборка звуков: `uv run scripts/sfx.py bed <вариант>` → `sfx.wav`; `composite.py final`
подмешивает её сам. Свои файлы звуков — в папке `папки.звуки` (whoosh.wav …), иначе синтез.

## PLAN.md (что видит автор)

```markdown
# План: C0001 — v1 (full)

Длина 36.6 с · субтитры: по слову · акцент: лайм · наезды: да · музыка: да · текст за головой: нет
Под вставками 24.3 с из 36.6; б-роллов 24, карточек 2

| время | слово | что появляется | раскладка | наезд |
|---|---|---|---|---|
| 0.00–1.44 | «Сейчас» | спикер | — | наезд 1.00→1.05 |
| 1.44–2.68 | «одну» | б-ролл github.mp4 @19.8 ×2.2 — выделение команды → Copied! | half | наезд 1.00→1.05 |
| 5.00–7.64 | «Без» | карточка «плитки» | карточка | вжух «бесплатно» 1.15→1.27 |

## Предупреждения
- ⚠ #7 9.92–10.38: вставка 0.46 с — вне ориентира 0.5–1.8 с

## Нет ассета
- 24.10 с «расписанию»: табло часов публикаций → карточка или motion-assets
```

Первые строки таблицы — это хук: по ним видно, начинается ли ролик с результата.
