# Карточки переднего слоя

Читать, когда в плане нужна карточка (нет б-ролла или ассета, а мысль важная).

Карточка висит сверху кадра (top 190 px), лицо остаётся под ней. Цвета — только
из темы автора. Все моменты внутри карточки — якоря на слова (`at`), как в
plan.json: элемент появляется ровно на слове. Без `at` — равномерно после входа.
`"top": 1100` в пункте плана опускает карточку (например, когда верх занят).

| Шаблон | Когда | Слоты |
|---|---|---|
| `tiles` | «без X, без Y, и Z» — перечёркнутые варианты и один «да» | `items: [{icon, label, crossed?, ok?, at}]` |
| `terminal` | команда, установка, вывод | `title, command, type_from?, type_to?, lines: [{text, at, ok?}]` |
| `profile` | «канал есть», «бот создан» — объект готов | `icon (эмодзи или .svg), title, subtitle, pill?, pill_at?` |
| `chips` | источники, теги, списки по группам | `title, subtitle?, subtitle_at?, groups: [{label, label_at?, icon?, accent?, chips: [{text, at?}]}]` |
| `rewrite` | было → ИИ → стало | `title, source_label, target_label, badge?, badge_at?, text, text_at?, type_to?` |
| `rows` | расписание, статусы, очередь | `title, rows: [{left, right, state: ok|wait, at?}]` |
| `compare` | «сервер, а не компьютер» — две половины | `items: [{icon, title, note, state: ok|dim, at?, note_at?}]` (2 шт.) |
| `buttons` | окно бота с кнопками, нажатия по словам | `avatar, title, subtitle, message, hint?, show_at?, buttons: [{text, press_at?}]` |
| `cta` | финал: «Напиши СЛОВО в комменты» | `lead, word, sub?, sub_at?, size? (190), lead_px? (36), sub_px? (32)` |
| `sticker` | наклейка в точке кадра: заклеить рот на мате, отметить жест | `text (эмодзи), x, y, size? (180), rotate? (−10)` |
| `filmstrip` | плёнка по бокам кадра: перфорация едет всё быстрее, вдоль — слово вертикально | `text, width? (150)` |
| `logos_cut` | иконки сервисов влетают, вспышка режет их по диагонали, половинки падают | `icons [файлы], cut_at, size? (240), top? (300)` |
| `thought` | облачко-мысль над головой: «видишь фишку и думаешь…» — суть, которую надо подсветить | `x, y, w, h` (облако), `head: [x, y]` (откуда кружки), `marks: [{text, at, size?}]` (знаки по словам: «?», «✨») |
| `chat` | живая переписка (светлая): «печатает…», сообщение по буквам, ответ автора с аватаркой | `name, avatar, status?, msg, msg_from, msg_to, reply, reply_at, me` (фото автора) |
| `cc_terminal` | терминал Claude Code в окне macOS: приветствие с маскотом, просьба печатается, ответ строками | `title, request, type_from, type_to, brand (цвет), mascot, lines: [{text, at, kind: think|tool|ok}]` |

Кодовое слово и форма CTA — из настроек (`cta`), не выдумывай. Слово, которое
автор произносит в кадре, должно совпасть с карточкой. Карточка `cta` — только когда
CTA ролика `код`; при `ссылка` финал — 3D-концовка `end_card` из библиотеки
(`plan-format.md`, «Концовка-ссылка»).

## Пример

```json
{"kind": "card", "template": "terminal", "from": "Берешь", "to": {"word": "Канал", "shift": -0.06},
 "slots": {"title": "сервер — terminal", "command": "curl -fsSL https://example.org/install.sh | bash",
           "type_to": {"word": "команду", "shift": 0.5},
           "lines": [{"text": "→ Docker уже стоит … ✓", "at": "запускаешь"},
                     {"text": "✓ Готово.", "at": "ставит", "ok": true}]}}
```

## Чего здесь нет

Сцены сложнее карточки (объёмные иконки, сквозные объекты, метафоры) — это
`motion-assets`: там шаблоны рендерятся в ассеты библиотеки и переиспользуются.
Нужная карточка повторяется из ролика в ролик — повод сделать её сценой в
библиотеке, а не рисовать заново.
