# reel — рилс из сырой записи без монтажки

Кидаешь запись говорящей головы (и отдельный звук с петлички, если писал) — получаешь
вертикальный рилс 1080×1920: тишина и дубли вырезаны, субтитры по словам на русском,
на ключевые слова встают б-роллы, ассеты или карточки, на склейках — наезды, под
голосом — музыка, громкость сведена. Перед рендером скилл показывает план-таблицу
(время / слово / что появляется / раскладка / наезд) и ждёт твоего «ок».

Проверено на живом ролике: рилс 36 с, 24 вставки по словам, субтитры по слову с
градиентным акцентом, наезды, музыка — около 5 минут счёта на Apple Silicon.

## Требования

- **ffmpeg / ffprobe**, **Node.js** (`npx` — для рендера HyperFrames), **uv**.
- Соседний скилл **rough-cut** — первая стадия (резка). Ставятся вместе.
- macOS — центр лица для наездов через Apple Vision; на других ОС наезды идут от
  центра кадра.
- Опция «текст за головой» — маска RobustVideoMatting (PyTorch, ставится через uv
  при первом запуске; CPU или Apple MPS).

## Как пользоваться

- «Собери рилс из `C0001.MP4`, звук `rec.mov`» — полный режим: резка → план → «ок» → ролик.
- «Наложи субтитры на `final.mp4`» — режим `subs`: только субтитры поверх готового монтажа.
- «Порежь и подпиши, без вставок» — `cut+subs`.
- После показа: «субтитры ниже», «на „сервере“ поставь терминал» — правка плана или
  настроек, пересборка только задетого слоя.

## Режимы

| Режим | Что делает |
|---|---|
| `cut` | только резка (rough-cut) |
| `cut+subs` | резка + субтитры |
| `subs` | субтитры поверх уже смонтированного файла |
| `full` | резка, субтитры, вставки по плану, наезды, музыка |

Опции: `behind_text` (крупный текст за головой — дорого, по умолчанию выкл.),
`music`, `zoom`, `brolls`.

## Выход

```
export/
  <стем> — <метка>.mp4   ← готовый ролик
  _сборка/               ← cut-list, черновой монтаж, расшифровка, план, слои — пока идёт работа
```

Отбракованные варианты, кадры и листы проверки удаляются сразу после выбора. Финал
принят — `_сборка/` удаляется целиком, в `export/` остаются только ролики. Исходники
удаляются только после «да» автора на прямой вопрос.

## Под себя

Скилл обезличен: всё твоё — в `reel.settings.json` в твоей рабочей папке (образец —
`assets/reel.settings.example.json`, ключи — `references/settings.md`):

- тема: цвета фона, акценты (сплошные и градиенты), шрифты **с кириллицей**;
- субтитры: строками с подсветкой или по одному слову, анимация появления, размер;
- музыка: трек + рецепт (где цикл, где тихое место для конца) или готовая подложка;
- словарь замен для расшифровки (как Whisper слышит твои слова и термины);
- CTA по площадкам, папки б-роллов и библиотеки ассетов (`motion-assets`).

Путь к файлу — в `.env` (`REEL_SETTINGS=…`, шаблон `.env.template`) или просто держи
`reel.settings.json` в папке, откуда запускаешь Claude. Рядом скилл ведёт `lessons.md` —
твои правки, которые не выражаются параметром; читается при каждом запуске.
