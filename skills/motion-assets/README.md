# motion-assets — библиотека моушн-графики

Склад, который живёт дольше одного ролика: моушн-сцены в твоём стиле, твои
обработанные б-роллы и оверлеи — каждый с описью «что и на какой секунде видно».
Скилл `reel` ставит их на ключевые слова сам, а в CapCut или Resolve их можно брать
руками.

## Что умеет

- **Сцены из шаблонов** в твоей теме: монета-иконка с переворотом, источники →
  бот, пост в 3D со сканированием и печатью текста, табло с перелистыванием цифр,
  3D-концовка на твоём настоящем профиле: ссылка выходит плашкой / клик с подсказкой /
  наезд камеры — для финала «ссылка в шапке профиля» вместо кодового слова.
  Для длинных роликов 16:9 — подписка YouTube → Telegram на настоящих интерфейсах:
  курсор жмёт «Подписаться», переходит по ссылке в шапке и подписывается на канал.
  Заголовок по словам с акцентом, слоты под текст, числа и иконку. Раскладки:
  на весь экран, на верхнюю половину или оверлей.
- **Опись своих б-роллов:** переходы считаются сами, а события («команда видна
  целиком», «клик», «выделено») и приватные окна (IP, ключи, токены) скилл
  размечает, глядя на контакт-листы.
- **Обработка б-ролла** в новый файл: кадр 9:16, плавный наезд на место, размытие
  приватного, ускорение пустых участков. Оригинал не трогается.
- **Оверлеи:** `.mov` с альфой (ProRes 4444) и `.mp4` на зелёном для хромакея в CapCut.
- **Каталог приёмов:** страница-сетка всей библиотеки — у каждого ассета постоянный номер,
  название, «когда брать», теги; поиск, фильтры, клик — видео играет. Это обычный HTML-файл
  `<библиотека>/_каталог/index.html`: открывается двойным кликом, без интернета, и пересобирается
  сам после каждого нового ассета. На свой сервер по IP — `python3 scripts/catalog.py deploy-help`.

## Как пользоваться

- «Сделай сцену „табло“: было 3 часа — стало 0, подпись „на рутину в день“».
- «Опиши б-ролл `terminal.mp4` и добавь в библиотеку».
- «Размой ключ на `tg-flow.mp4` с 20,5 до 23,5 с».
- «Что есть в библиотеке про сервер?»

## Требования

ffmpeg, Node.js (`npx` для рендера HyperFrames), соседний скилл `reel` (общая тема
и движок). Python — только стандартная библиотека.

## Под себя

Тема и путь библиотеки — в том же `reel.settings.json`, что и у `reel`:
`тема` (цвета, акценты, шрифты с кириллицей) и `папки.библиотека_ассетов`.
Библиотеку держи вне репозитория и вне заметок: там видео.

```
<библиотека>/
  index.json      ← опись всех ассетов
  <id>/           ← файлы ассета (mp4 / mov / green / preview / проект сцены)
```
