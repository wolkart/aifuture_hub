# Шаблоны сцен

Сцена = шаблон + слоты + тема автора. Собирает `scene.py`:

```
scene.py list                                   — шаблоны и слоты с дефолтами
scene.py <шаблон> --id <id> --slots slots.json [--theme dark|light] [--layout full|half|overlay] --render
```

Опись событий для `index.json` шаблон пишет сам из своих таймингов.

## Каталог

| Шаблон | Тема | Слоты | События | Когда брать |
|---|---|---|---|---|
| `coin_flip` — монета-иконка | тёмная | `headline`, `context`, `icon`, `coin` (secondary · accent · #hex), `tags` | слова заголовка, акценты, иконка влетает (0,15), видна целиком (0,75), переворот (~1,75), кольца, уход | представить один объект крупно: инструмент, сервис, канал |
| `sources_bot` — источники → бот | светлая | `context`, `headline`, `sources` (1–4), `bot`, `result` (пусто → «+N источников»), `tags` | плашки слетаются, все видны, бот появляется, всасывает, пульс, итог | «на вход несколько вещей — система их переваривает» |
| `post_3d` — пост в 3D | тёмная | `context`, `headline`, `name`, `time`, `text`, `badge`, `tags` | карточка влетает, видна целиком, бейдж, сканирование, строки исчезают, печать, текст целиком | нейросеть переписывает/генерирует/проверяет текст |
| `flip_board` — табло | светлая | `context`, `headline`, `from`, `to`, `unit`, `subline`, `notes` (0–4 `[текст, время]`), `tags` | табло появляется, каждое перелистывание, итог, заголовок, строки с галочкой | «было N — стало M», расписание результата |

Длительность — 3,3–4,5 с, растёт со слотами (длинный заголовок, длинный текст поста, больше перелистываний). Тема меняется флагом `--theme`: светлый шаблон можно собрать тёмным и наоборот.

## Слоты — общее

- **Заголовок** собирается по словам, каждое влетает blur → резкость. Разметка: `*слово*` — акцент темы, `_слово_` — второй цвет (`secondary`), можно на несколько слов (`*твой стиль*`), `\n` — перенос строки. Шаг между словами считается сам по их числу (0,12–0,28 с), кегль уменьшается для длинных заголовков.
- **Иконка** — эмодзи/символ или путь к SVG/PNG/JPG/WEBP (относительный — от папки `slots.json`). Файл копируется в проект. Чужих логотипов в шаблонах нет: нужен значок сервиса — передай свой файл.
- **Цвета и шрифты** — только из темы автора (`reel.settings.json`): фон тёмный/светлый, `secondary`, акцент (на светлом — его пара `on_light`), `text_dark`, `muted`, `success`, основной и крупный шрифт с кириллицей. В шаблонах ни одного цвета автора — тест это проверяет.

## Раскладки

- `full` — 1080×1920, фон темы с размытыми плавающими словами (на светлом — ещё мягкие пятна).
- `half` — 1080×960 для верхней половины кадра: та же сцена, ужатая по высоте.
- `overlay` — без фона и декора, прозрачная: `.mov` ProRes 4444 с альфой + `-green.mp4` на #00FF00 для хромакея в CapCut. На overlay у заголовка тень — чтобы читался поверх видео.

## Новый шаблон

Модуль `templates/<имя>.py`: `NAME`, `TITLE`, `DEFAULT_KIND`, `SLOTS` (`about` + нейтральный `default`), `BOX` (вертикальные границы содержимого — для `half`), `build(slots, theme, kind=None, layout="full")`. Общие куски — в `_common.py` (палитра, заголовок, декор, раскладка). Тесты подхватывают новый модуль сами.

Анимация seek-safe — рендер перематывает таймлайн покадрово:
- только `transform` / `opacity` / `filter`; `top`/`left` не анимировать;
- `fromTo`; повторный твин того же элемента (уход, пульс, переворот) — с `immediateRender: false`, иначе его начальное значение встанет с нулевого кадра;
- никаких `tl.call` с подменой текста: меняющиеся значения лежат стопкой, видно одно;
- селекторы по `id`; ни `Math.random`, ни `Date.now`.

## Планка качества

Проба уступает референсу в трёх местах — туда и расти:
- **объёмные иконки** — отрисованное 3D, а не плоский значок на монете;
- **сквозные объекты** — предмет переходит из сцены в сцену, а не каждая сцена с нуля;
- **метафоры сложнее карточки** — действие, которое объясняет механизм.
