# Шаблоны сцен

Сцена = шаблон + слоты + тема автора. Собирает `scene.py`:

```
scene.py list                                   — шаблоны и слоты с дефолтами
scene.py <шаблон> --id <id> --slots slots.json [--theme dark|light] [--layout full|half|overlay] --render
```

Опись событий для `index.json` шаблон пишет сам из своих таймингов.

## Горизонтальные 16:9 (`wide_*`) — куски «говорящая голова» в длинных роликах

Холст 1920×1080, модуль объявляет `FORMAT = "16:9"` и свою раскладку по умолчанию (`DEFAULT_LAYOUT`):
`overlay` — прозрачный `.mov` на дорожку над видео, `full` — на светлом фоне темы. `half` нет.
Система одна на все (`_wide.py`, снята с `_референсы/voronkov-claude-montage` и `labada-popups`):
белые карточки с мягкой тенью, синий градиент из `secondary` и тёмного текста темы, каждый элемент
проявляется из размытия с подъёмом за ~0,25 с на 0,1–0,15 с раньше своего слова, группа уходит общим
размытием, пока висит — едва покачивается. **Основа — `wide_drawer`** (светлая панель с группами,
автор 2026-10-18: «основой должны быть эти штуки — лучше цепляют взгляд»); всплывашки вокруг головы —
мелкие акценты между панелями. Звуки появления шаблон расставляет сам (`sfx`: вжух — панель, щелчок —
элемент, свист — смена группы); `scene.py --render` синтезирует их (`reel/scripts/sfx.py cues`) и вшивает
в .mov/.mp4 + кладёт `<id>-sfx.wav`. Лицо не перекрывать: центр лица — `face_centers.py` из `reel`
(медиана по куску), а не на глаз (2026-10-18 на глаз промахнулся на 0,1 кадра).

| Шаблон | Раскладка | Слоты | Когда брать |
|---|---|---|---|
| `wide_list` — список сбоку | overlay | `rubric`, `rubric_icon`, `items` (1–4 `{icon, title, sub, at}`), `side`, `duration` | перечисление в речи: шаги, причины, «что нужно» |
| `wide_chips` — чипы вокруг головы | overlay | `items` (2–6 `{icon, label, at}`), `head` [x, y], `spread`, `duration` | короткий перечень: инструменты, симптомы, что режем |
| `wide_number` — крупное число | overlay | `value` (`*часть*` — синим), `caption`, `at`, `place` (chest · right · left), `head`, `duration` | названная цифра: цена, срок, результат — ~3 с |
| `wide_message` — сообщение у головы | overlay | `name`, `avatar`, `time`, `text`, `reply`, `at`, `reply_at`, `side`, `duration` | «написал — ответил», вопрос подписчика, сообщение клиента |
| `wide_follow` — подписка YouTube → Telegram | full | `yt_name`, `yt_handle`, `yt_about`, `yt_link`, `yt_more`, `yt_avatar`, `yt_logo`, `yt_logo_text`, `videos` (до 3 `{image, title}`), `grid`, `tg_title`, `tg_handle`, `tg_about`, `tg_avatar`, `at`, `yt_at`, `link_at`, `tg_at`, `duration` | «подписывайтесь на YouTube и в Telegram»: курсор жмёт «Подписаться», кликает ссылку в шапке, YouTube уезжает влево, справа канал в Telegram — и там «Подписаться». Свои данные автора — в `_профили/follow/follow.json` библиотеки |
| `wide_drawer` — светлая панель с группами (**основа**) | full | `face` (кусок записи камеры), `face_start`, `focus_x`, `panel`, `open_at`, `close_at`, `groups` (`{at, type: list · message · number · compare · text, rubric, title, …}`) | основа кусков в камеру: панель выезжает, автор уезжает в левую часть, группы сменяются по словам размытием; в монтажке клип кладётся поверх его кадра, голос — с основной дорожки |

`at` — секунда слова **от начала сцены**; сцена встаёт на таймлайн так, чтобы её 0 совпал с её местом в ролике.

## Слоты — общее

- **Заголовок** собирается по словам, каждое влетает blur → резкость. Разметка: `*слово*` — акцент темы, `_слово_` — второй цвет (`secondary`), можно на несколько слов (`*твой стиль*`), `\n` — перенос строки. Шаг между словами считается сам по их числу (0,12–0,28 с), кегль уменьшается для длинных заголовков.
- **Иконка** — эмодзи/символ или путь к SVG/PNG/JPG/WEBP (относительный — от папки `slots.json`). Файл копируется в проект. Чужих логотипов в шаблонах нет: нужен значок сервиса — передай свой файл.
- **Цвета и шрифты** — только из темы автора (`reel.settings.json`): фон тёмный/светлый, `secondary`, акцент (на светлом — его пара `on_light`), `text_dark`, `muted`, `success`, основной и крупный шрифт с кириллицей. В шаблонах ни одного цвета автора — тест это проверяет. Исключение — настоящий интерфейс площадки
  (тёмные темы YouTube и Telegram в `wide_follow`): его цвета шаблон объявляет в `UI_COLORS`, и тест пропускает только их.

## Концовка-ссылка (`end_card`)

Финал ролика с призывом перейти по ссылке, на **настоящей** шапке профиля автора. Это
анти-кодовое слово: слота под СЛОВО нет, а `reel` не даст поставить концовку и карточку
с кодовым словом в один ролик (`cta.тип: код | ссылка`).

- **Источник** — `profile`: скриншот (лучше) или запись профиля + `profile_at` (кадр
  берётся ffmpeg-ом в кеш, оригинал не трогается). Скриншот резче и статичен; запись
  нужна, только если скриншота нет. Скриншоты автора лежат в библиотеке, `_профили/`.
- **Разметка** в пикселях источника: `crop` — шапка (аватар, имя, ссылка), `link_box` —
  где ссылка. Снять координаты: `ffmpeg -i shot.png -vf "crop=…,drawgrid=w=50:h=50:t=1:c=red@0.6" grid.png`
  и посмотреть. Обрезай по смыслу: широкую шапку (YouTube) — до аватара, имени и ссылки,
  иначе карточка выйдет полоской с мелким текстом. Что не должно попасть в кадр
  (устаревшее «N лет» в описании, чужие уведомления), отрезай обрезкой.
- **Ссылка на плашке набрана шрифтом темы** (`link`), а не вырезана из скриншота:
  вырезка с телефона мылится при увеличении, набор резкий при любом.
- **Приём** (`highlight`): `pop` — ссылка выходит из карточки плашкой к зрителю, тап;
  `click` — курсор/тап, маркер под ссылкой, подсказка над ней (или под ней, если ссылка в
  верхней части карточки — не закрывать имя); `zoom` — камера ныряет к ссылке, карточка
  в размытие. `pointer: auto` — у `click` курсор, у остальных тап; для десктопного
  скриншота (YouTube) ставь `cursor`, для телефона — `tap`.
- **Цвет выделения** `glow: auto`: на тёмной теме акцент, на светлой — второй цвет
  (светлые пары акцента на белом бледнеют). Тон скриншота `tone: auto` меряется по
  средней яркости шапки и задаёт цвет плашки.
- Длина 5 с; после тапа — удержание со свечением и редкими волнами, кадр не замирает.
  В `reel` ставится последним пунктом до конца ролика.

## Раскладки

- `full` — 1080×1920, фон темы с размытыми плавающими словами (на светлом — ещё мягкие пятна).
- `half` — 1080×960 для верхней половины кадра: та же сцена, ужатая по высоте.
- `overlay` — без фона и декора, прозрачная: `.mov` ProRes 4444 с альфой + `-green.mp4` на #00FF00 для хромакея в CapCut. На overlay у заголовка тень — чтобы читался поверх видео.

## Новый шаблон

Модуль `templates/<имя>.py`: `NAME`, `TITLE`, `DEFAULT_KIND`, `SLOTS` (`about` + нейтральный `default`), `BOX` (вертикальные границы содержимого — для `half`), `build(slots, theme, kind=None, layout="full")`. Общие куски — в `_common.py` (палитра, заголовок, декор, раскладка). Тесты подхватывают новый модуль сами.

Анимация seek-safe — рендер перематывает таймлайн покадрово:
- только `transform` / `opacity` / `filter`; `top`/`left` не анимировать;
- `fromTo`; повторный твин того же элемента (уход, пульс, переворот) — с `immediateRender: false`, иначе его начальное значение встанет с нулевого кадра;
- никаких `tl.call` с подменой текста: меняющиеся значения лежат стопкой, видно одно;
- селекторы по `id`; ни `Math.random`, ни `Date.now`.

## Планка качества

Проба уступает референсу в трёх местах — туда и расти:
- **объёмные иконки** — отрисованное 3D, а не плоский значок на монете;
- **сквозные объекты** — предмет переходит из сцены в сцену, а не каждая сцена с нуля;
- **метафоры сложнее карточки** — действие, которое объясняет механизм.
