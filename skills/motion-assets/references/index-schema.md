# Библиотека и `index.json`

Библиотека — папка автора **вне репозитория и вне волта** (видео в волте не храним). Путь — в `reel.settings.json`, ключ `папки.библиотека_ассетов`; скрипты берут его оттуда или из `--library`.

```
<библиотека>/
  index.json                 ← опись всех ассетов
  <id>/                      ← одна папка на ассет
    index.html, assets/      ← проект HyperFrames (у сцен из шаблона)
    <id>.mp4                 ← full/half
    <id>.mov, <id>-green.mp4 ← overlay: альфа и зелёный фон
    <id>-preview.png
```

## Запись

| Поле | Что | Обязательно |
|---|---|---|
| `id` | имя папки и ключ; буквы, цифры, `-`, `_`, `.`; уникален | да |
| `kind` | `scene` (сцена из шаблона) · `broll` (свой обработанный б-ролл) · `overlay` (на прозрачном) | да |
| `layout` | `full` 1080×1920 · `half` 1080×960, верхняя половина кадра · `overlay` 1080×1920 с альфой | да |
| `duration` | секунды, из реального файла | да |
| `theme` | `dark` · `light` — какой фон (у б-ролла — интерфейс) | да |
| `tags` | слова для поиска — на том языке, как слово звучит в ролике («телеграм», а не только «telegram»): `/reel` ищет по словам расшифровки | — |
| `describes` | одна строка: что в кадре | — |
| `events` | `[{t, what}]` по возрастанию `t`, внутри `0…duration` | — |
| `transitions` | `[[a, b]]` — окна переходов и наездов (б-ролл) | — |
| `private` | `[{from, to, what}]` — запретные окна (б-ролл) | — |
| `slots` | слоты, с которыми собрана сцена (пересборка) | — |
| `template` | имя шаблона сцены | — |
| `files` | `{роль: путь}` — **только относительно библиотеки**: `mp4`, `mov_alpha`, `green`, `preview`, `project` | — |

Лишние поля не мешают. `library.py validate` проверяет схему и наличие файлов (нет файла — предупреждение, не ошибка).

```json
{ "id": "term-deploy", "kind": "broll", "layout": "full", "duration": 9.6, "theme": "dark",
  "tags": ["терминал", "деплой", "сервер"],
  "describes": "запись терминала: команда деплоя, бегут строки, зелёное «done»",
  "events": [{"t": 0.5, "what": "команда видна целиком"},
             {"t": 2.0, "what": "клик «Enter»"},
             {"t": 6.5, "what": "строка «done» выделена зелёным"}],
  "transitions": [[1.2, 1.6], [4.0, 4.9]],
  "private": [{"from": 7.0, "to": 8.5, "what": "IP сервера в заголовке окна"}],
  "files": {"mp4": "term-deploy/term-deploy.mp4"} }
```

## События, не темы

Событие — то, что видно в конкретный момент: **что появилось, что выделено, где клик, где объект виден целиком** (команда, ссылка, кнопка). Шаг — 0,5 с. «Про деплой» — это тег, а не событие.

- У сцен события пишет сам шаблон из своих таймингов — руками ничего не нужно.
- У б-ролла — агент по контакт-листам `scan_broll.py` (2 к/с, таймкод на каждом кадре); спорный момент — точечный кадр `--at <t>`.

## Переходы

`scan_broll.py` считает их сам: разница соседних кадров (10 к/с, 108×192, серое) больше 4 → движение. Окна ближе 0,2 с сливаются: запись экрана с авто-зумом иначе даёт десятки мелких. Кадр на переходе размыт — вставка туда не ставится.

## Приватное

IP, ключи, токены, почты, личные имена в интерфейсе. Два пути:
- **запретное окно** в `private` — `/reel` не берёт этот кусок;
- **размытие в копии** — `broll_edit.py --blur x,y,w,h,from,to` (доли кадра и секунды оригинала); оригинал не трогается, после обработки опись делается заново по новому файлу.

## Как это читает `/reel`

1. Слово из плана → `library.find(index, слово)`: теги весят больше описания и событий, ё = е, регистр не важен, все слова запроса должны найтись.
2. Точка входа вставки 0,5–1,8 с — внутри `library.usable_windows(entry, min_len)`: вся длительность минус переходы и приватные окна (`pad` расширяет их).
3. Лучше всего — отрезок, который начинается с события «виден целиком».
4. Раскладка вставки = `layout` ассета; `overlay` кладётся файлом `mov_alpha`.
5. Нет подходящего ассета — в плане строка «нет ассета → карточка или `motion-assets`», на лету ничего не рисуется.

## CLI

```
library.py list | find <запрос> [--kind] [--layout] [--theme] | show <id> | validate | add <запись.json>
            [--library <папка>] [--settings <reel.settings.json>] [--json]
```
