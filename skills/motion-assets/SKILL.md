# motion-assets — библиотека моушн-графики

Ты ведёшь склад, а не монтируешь ролик. Ассет делается один раз и потом
переиспользуется: в `/reel` по описи или руками в монтажке. Поэтому важнее всего
**опись**: какие события и в какие секунды видны, где переходы, где приватное.
`/reel` верит описи — ошибка в ней всплывёт в чужом ролике.

Пути `scripts/…`, `templates/…` — от папки этого скилла. Тема (цвета, шрифты с
кириллицей, акценты) и путь библиотеки — из `reel.settings.json` автора (общий с
`/reel`, ключ `папки.библиотека_ассетов`); нет файла — нейтральная тема и
`--library <папка>`. Скилл использует общий код соседнего `reel`.

## Режимы

**Найти** — что уже есть:

```bash
python3 scripts/library.py find "<слова>" [--kind scene|broll|overlay] [--layout full|half]
python3 scripts/library.py show <id>
```

Прежде чем делать новый ассет — поищи: похожий уже лежит, а тот же объект в
разных роликах узнаётся.

**Сцена из шаблона.** `python3 scripts/scene.py list` — шаблоны и слоты.
Заполни `slots.json` под мысль (заголовок по словам, `*слово*` — акцент) и:

```bash
python3 scripts/scene.py <шаблон> --id <id> --slots slots.json [--layout full|half|overlay] [--theme dark|light] --render
```

События для описи шаблон пишет сам. Рендер 6–17 с. Посмотри 2–3 кадра из готового
файла (`<id>-preview.png` и кадры через `ffmpeg -i … -ss T -frames:v 1`) —
кириллица в шрифте темы, ничего не вылезает за кадр. Каталог, слоты и
планка качества — `references/templates.md`.

**Свой б-ролл** (запись экрана, съёмка):

1. Нужна обработка — сначала она, в новый файл библиотеки; оригинал не трогается:
   ```bash
   python3 scripts/broll_edit.py <видео> --id <id> [--focus-x 0.4] [--zoom t0,t1,cx,cy,масштаб] \
     [--blur x,y,w,h,from,to] [--speed a,b,скорость] [--print]
   ```
   Координаты и время — оригинала (как на листах), доли кадра 0…1.
2. Опись — всегда по **итоговому** файлу (после ускорения таймкоды съезжают):
   ```bash
   python3 scripts/scan_broll.py <файл> --out <папка> --id <id>
   ```
   Скрипт сам считает переходы и кладёт контакт-листы (2 к/с, таймкод на кадре) и
   заготовку `<id>.entry.json`. Посмотри **каждый** лист (Read) и впиши в заготовку
   события с шагом 0,5 с — что появилось, что выделено, где клик, где объект виден
   целиком — и приватные окна. Спорный момент — точечный кадр `--at <t>`.
   Затем `python3 scripts/library.py add <id>.entry.json`.
   Формат записи — `references/index-schema.md`.

**Оверлей** — та же сцена с `--layout overlay`: `.mov` ProRes 4444 с альфой и
`-green.mp4` на #00FF00 для хромакея в CapCut.

## Красные линии

- **Приватное в описи обязательно.** IP, ключи, токены, почты, личные имена — даже
  на долю секунды. Найдено — окно в `private` или размытая копия через `--blur`. В
  прототипе в б-роллах нашлись IP сервера в заголовке терминала и API-ключ целиком
  на 3 с. Ключ, который уже где-то публиковался, — повод сказать автору перевыпустить
  его, а не только размыть.
- **Оригиналы не трогаются**, всё новое — в папке библиотеки.
- **События, а не темы.** «Про деплой» — тег; событие — «2,0 с: клик Enter».
- **Чужих логотипов и бренд-иконок в шаблонах нет** — значок сервиса приходит
  файлом слотом.

## Отчёт

```
Ассет: <id> · <kind>/<layout>/<theme> · <длина> с → <путь к файлу>
События: <N> (первое: <t> <что>)
Приватное: <окна> | не найдено (просмотрено листов: <N>)
Индекс: <путь index.json> · записей <N> · validate: 0 ошибок
```

Строка «Приватное» пишется всегда — она показывает, что листы смотрели глазами.
Для сцены из шаблона она: «Приватное: не применимо (сцена из шаблона)».

## Границы

- Монтаж ролика и выбор вставок по словам — `reel`.
- Новый шаблон сцены — модуль в `templates/` (как устроен — `references/templates.md`);
  делать, когда одна и та же карточка `/reel` повторяется из ролика в ролик.
