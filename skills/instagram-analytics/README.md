# instagram-analytics — где применять

Скилл разведывает нишу/конкурентов в Instagram через Apify: по профилю или ссылкам собирает посты/рилс с метриками, ранжирует «что залетело» по кратности к медиане автора и выгружает в **структурированную базу** (Markdown-индекс + карточки + CSV). Это разведка для **своего контента** (референс → переупаковка), а не репост.

## Когда срабатывает

- «Разбери конкурента / нишу», «что залетает у X», «выгрузи рилс/посты конкурента в таблицу/базу», «собери референсы рилс», «проанализируй профиль».
- «Разбери мой аккаунт», «что у меня залетало» — свой профиль тем же путём.
- «Вот моя статистика», «почему этот рилс не залетел» — со скринами Insights своего аккаунта (режим `audit`).

НЕ для сбора Insights (их приносит автор), не для поиска по хештегу, не для скачивания одного поста (это `instagram-downloader`), не для дословного репоста.

## Три режима

- **`scout`** (дефолт) — массово и дёшево: метрики + ранжирование по кратности + выгрузка базы.
- **`enrich`** — выборочно по отмеченным рилс: аудио → транскрипт → разбор сценария (хук/тело/CTA), дописывается в карточку.
- **`audit`** — свой аккаунт по скринам Insights: пропуски, отправки, удержание, подписки → «проблема хука или профиля» → `Аудит <дата>.md`.

**Кратность** — во сколько раз пост обогнал обычный день своего автора: рилс — просмотры / медиана его рилсов, карусель — лайки / медиана его каруселей. Голые просмотры врут: 400 тысяч у миллионника — тихий день, у аккаунта на 4 тысячи — находка. Идея — из `ig-viral` Джейка Шинкариола (instagram-agent-skill, MIT).

## Настройка `.env`

```
cp .env.template .env
# APIFY_TOKEN=<твой токен Apify>
# APIFY_ACTOR=<актор IG-скрейпера; дефолт apify~instagram-scraper>
# ASR_PROVIDER=openai|local|apify|none   (для enrich; none = без транскрипта)
# OPENAI_API_KEY=<если ASR_PROVIDER=openai>
# APIFY_ASR_ACTOR=<если ASR_PROVIDER=apify>
# OUTPUT_DIR=<куда писать базу; дефолт ./instagram-analytics-output, можно путь к Obsidian-волту>
```

## Выгрузка

**Папка на блогера:** `<OUTPUT_DIR>/<author>/index.md` (ранжированная таблица, колонка «Тема» = кликабельная ссылка в карточку) + `cards/<id>.md` (карточка: `aliases`+читаемый заголовок, при `enrich` — транскрипт + **дословный перевод на русский** + разбор) + `export.csv` (для Sheets). Плюс `<OUTPUT_DIR>/_Разведка.base` — Obsidian Base со сводным кросс-блогерным срезом (фильтр по автору, сортировка по кратности). Видео не хранятся (только `video_url`). Единая схема — мостик к будущей БД/веб-интерфейсу.

## Хэндофф

- рилс → `reels-script`; пост/карусель → `carousel-script` (с нишей пользователя).

## Примеры вызова

```
разбери конкурента @nik.travel — выгрузи последние рилс с метриками
```

```
enrich: обработай по полной топ-3 из последней разведки
```

В ответ — сводка выгрузки и пути к файлам базы (при enrich — краткий разбор сценариев).
