# Настройки длинного ролика

Читать, когда настроек нет или правка автора выражается параметром.

Тема, шрифты, папки звуков и библиотеки — общие с рилсами, в `reel.settings.json` автора
(`../reel/references/settings.md`). Своё у длинного ролика — раздел `ютуб` того же файла;
образец — `assets/settings.example.json`. Нет раздела — значения по умолчанию ниже.

| Ключ | Что | По умолчанию |
|---|---|---|
| `ютуб.музыка.скринкаст` / `голова` | `трек`, `цикл: [A, B]` (кусок, который повторяется без шва), `уровень_LU_к_голосу`, `подъём_в_паузах_dB`, `кроссфейд_с` | скринкаст −28 LU, без подъёмов; голова −20 LU, +4 dB; кроссфейд 4 с |
| `ютуб.пробы_музыки` | файлы и папки треков для проб (берутся первые три) | — |
| `ютуб.логотипы` | папка SVG-логотипов | `<библиотека>/_логотипы` |
| `ютуб.лицо_x` | где лицо по горизонтали в кадре головы (панели wide_drawer) | 0.47 |

**Цикл.** Без него трек повторяется целиком (вступление звучит снова). Снять цикл:
найти долю, с которой начинается ровная часть, и взять кусок длиной в целое число тактов
так, чтобы `B − кроссфейд − A` было кратно такту — стык ляжет в долю (так снят цикл
«good for the ghost»: 80 BPM, 24,75–76,75 с = 16 тактов + 4 с кроссфейда).

**Права.** До публикации: сток с лицензией (сертификат — рядом с треком) или загрузка
ролика с ограниченным доступом и шаг «Проверки» YouTube (Content ID). Трек с претензией —
`music.py bed --track …` и `assemble.py` заново; клипы графики не трогаются.
