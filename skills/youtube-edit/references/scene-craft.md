# Ремесло сцен длинного ролика

Читать на стадии 8, перед тем как писать `scenes.py`. Всё ниже снято с правок автора по
ролику news-reposter (2026-10-19) — каждое правило с причиной; механизм, который его
держит, назван рядом. Где механизм есть, правило соблюдается само; где нет — это
ориентир, и автор вправе пойти против.

## Четыре вида

| Вид | Что | Когда | Как в коде |
|---|---|---|---|
| **Д** | сцена-действие на весь кадр: мини-скринкаст графикой, настоящие интерфейсы и логотипы | автор рассказывает о том, чего на экране нет (установка, сравнение, «как это работает») | `Ins(имя, начало, "full")` |
| **Э** | поверх экрана: вуаль, графика вокруг места показа, экран виден | экран висит ≥ 7 с, а автор объясняет понятие (`scan.json` → `static`) | `Ins(имя, начало, "over", veil=…)` |
| **П** | светлая панель `wide_drawer`: автор уезжает влево, группы сменяются по словам | говорящая голова перечисляет, сравнивает, цитирует сообщение | `drawer(имя, начало, конец, группы)` |
| **А** | акцент у головы: чипы, крупное число, сообщение, список | короткий перечень, названная цифра — 3–10 с | `Tpl(имя, "wide_chips" / "wide_number" / "wide_message" / "wide_list", …)` |

**Действия важнее всплывашек.** Автор: «слишком много вылеташек, мало анимационных
действий» — у ориентира (Воронков) курсор тащит, кликает, переключает. Панель с текстом
— реже, сцена с действием — чаще. Подписка YouTube → Telegram — готовый шаблон
`wide_follow` (данные автора — `_профили/follow/follow.json` библиотеки).

**Настоящие интерфейсы.** Шапки YouTube и Telegram — по скринам автора, логотипы — из
папки логотипов (`logo("n8n-color.svg")`, `ico(…)`), один и тот же продукт — одним и тем
же логотипом везде. Сервер — стойкой (`server-rack.svg`), не монитором. Числа, которые
меняются (подписчики, просмотры), не показывать.

**Факты в графике сверять с продуктом,** а не с памятью: в news-reposter неотвеченный
пост удаляется из очереди, а не публикуется — сцена сначала показывала наоборот.

## Время и темп

- **Без пустого входа.** «Три секунды тонировка — сидишь, ждёшь». Вставка начинается за
  ~0,35 с до первого элемента — это делает `fitted` сам (в выводе `build.py`: «начало
  позже на … с»).
- **Без висящей картинки.** «Картинка висит в воздухе и дожидается следующей анимации».
  Внутри сцены на ключевые слова что-то происходит примерно каждые 2 с: пульс того, о
  чём речь (`mark`), волна по группе (`wave`), встряска на «не так» (`shake`), плашка по
  смыслу, где показать нечем (`chip`). Паузы находит `build.py --gaps` вместе со словами,
  которые в них звучат, — действие ставь на эти слова.
- **Не мелькает.** Последний элемент живёт на экране ≥ 0,8 с до ухода (`check.py`:
  «мелькнуло»). Конец сцены считай от последнего элемента, а не от начала следующей фразы.
- **Время — словами.** `at(фраза, слово)` и `s.t(фраза, слово)`; слово — номер или начало
  («одной», «копир»). Секунды руками не пишутся: после «верни 3» в резке всё сдвинется само.
- **Встык, не внахлёст.** Две вставки одной дорожки не налезают больше чем на 0,45 с
  (`check.py`: «нахлёст»): конец первой — `s.t(<фраза следующей>, 0, 0, -0.7)`, если вторая
  выезжает за 0,4 с до своей фразы.

## Кадр

- **Ровная композиция.** «Всё ушло вправо, слева пустота». Пустая треть при графике в
  противоположной ловится `check.py post` по рендеру. Сцену, свёрстанную правой колонкой,
  целиком переносит влево `place=LEFT`.
- **Показ — поверх экрана, рассказ — можно перекрыть.** Автор что-то показывает мышкой →
  вставка Э, вуаль оставляет открытым место показа: `veil="light"` (показывают центр),
  `"right"` (показывают слева, графика справа), `"bands"` (полосу по центру), по умолчанию —
  затемнение слева, графика слева, справа экран и кружок камеры открыты. Просто
  рассказывает при статичном экране → можно Д на весь кадр.
- **Курсор — точно в цель.** «Мышка кликнула мимо — это надо всегда подправлять». Только
  `cursor_to("#кнопка", когда)` — кончик стрелки в центр элемента по разметке; координаты
  руками — для начальной точки (`cursor(x, y)`) и холостых ходов.
- **Всё время в движении** — сцена медленно наезжает (+3,5 %) сама, ничего делать не надо.
- Под вставкой Э по умолчанию — кусок той же резки таймлайна (клип непрозрачный, ~10 МБ);
  прозрачные Э (`build.py --alpha`) — только если на диске десятки гигабайт: с вуалью на
  весь кадр ProRes 4444 весит ~50 МБ/с.

## Звук

Звуки ставятся сами по событиям: `pop` (щелчок появления, 2–3 варианта по кругу из
папки звуков), `swish` / `whoosh` (вход сцены), `select` (выбор — `pick`), `tap` (клик,
пульс), `type` (печать — `s.type`), `reward` (крупная цифра, итог). Своё —
`s.sound(когда, "имя", dB)`. «Пробка» (`pop.wav` старый) автору не нравится — в папке
звуков он уже отклонён; приз-«сундучок» — только на особых появлениях.

## Каркас — шпаргалка

```python
from stage import *
s = Ins("имя", at(15, "одной") - 0.3, "full", what="для маркера и таймкодов")
s.add(html, "id1", "id2")              # id уйдут в конце сами
s.pop("#id1", s.t(16, "копир"))        # появление + щелчок; pop(sel, когда, звук, dB, длительность)
s.fade(sel, t) / s.out(sel, t)         # проявить / увести (от текущей прозрачности — без вспышки)
s.cursor(x, y, t) ; s.cursor_to("#btn", t)          # курсор и клик в центр элемента
s.type(len(cmd), t0, span)             # печать текста из typed(cmd)
s.pick("#card", "#cardk", "#other", t) # выбор зелёным с галочкой
s.mark(sel, t) ; s.wave([sel, …], t) ; s.shake(sel, t) ; s.chip(id, html, x, y, t, until=…)
s.style(css) ; s.file(путь) ; s.code('tl.to(…);') ; s.sound(t, "pop", -15)
return s.done(конец)                   # всё уходит в конец, хвост 0,3 с

drawer("p-имя", начало, конец, [группы wide_drawer], what=…)      # П; время в группах — at(…)
Tpl("имя", "wide_chips", начало, {слоты; at / *_at — at(…)}, what=…)   # А и прочие шаблоны
SCENES = [функция, …]
```

UI-куски: `window`, `term`, `mac_bar`, `pill`, `bubble`, `check`, `typed`, `logo`, `ico`,
`logo_path` (иконка для слотов шаблона). Остальное — HTML прямо в сцене; если кусок
повторяется во втором ролике — кандидат в шаблон `motion-assets`.
