# План графики и шлюз

Читать на стадии 5. План — `export/монтаж/plan.md`, его видит автор; сцены пишутся по нему
потом, поэтому правка плана стоит секунды, а правка отрендеренной сцены — минуты.

## Как набирать

1. Читай `words.json` кусками ~10 мин (как отчёт резки) и `scan.json`: `static` — экран
   стоит ≥ 7 с, а речь идёт (время записи; на таймлайн переводит `timeline.py`), `head` —
   куски, где автор в кадре целиком.
2. Ищи то, что можно **показать**: действие («копируете команду» → курсор копирует),
   сравнение («n8n против кода» → две колонки, выбор зелёным), перечень («Claude Code,
   Open Code, DeepSeek» → чипы), цифру («пять долларов — надолго» → крупное число),
   чужую реплику («подписчики просили» → сообщение).
3. Вид — по месту: голова → П или А (или Д, если рассказ длинный и показать есть что);
   висящий экран → Э; экран, где автор что-то показывает мышкой, — не трогать или Э с
   вуалью, открывающей место показа.
4. Плотность-ориентир — news-reposter (скринкаст, 39,6 мин): 46 вставок, 44 % ролика под
   графикой; у говорящей головы — что-то каждые 5–10 с. Нечего показать — не выдумывай
   вставку ради плотности: пусть идёт зум на голове.
5. Готовое — из библиотеки (`library.py find`), подписка — `wide_follow`.

## Таблица

```markdown
| # | Где | Вид | Что | Якорь |
|---|---|---|---|---|
| 1 | 00:50 | Д | «1 команда» → GitHub → курсор копирует → терминал → бот запущен, «Бесплатно» | 15 «одной» … 17 |
| 2 | 01:01 | П | «Что покажу»: как сделал / почему просто / инструкция → подписчик просил → «держите, целым роликом» | 18 … 22 |
| 3 | 04:12 | А | чипы Claude Code / Open Code / DeepSeek Harness у головы | 73 «claude» … 75 |
| 4 | 04:29 | Э | экран висит: «Сервис на коде — гибче ✓» против «n8n — свои костыли» (слева, вуаль) | 79 … 81 |
```

«Где» — время таймлайна (после резки), «Якорь» — номера фраз из отчёта резки: по ним
автор сверяется с текстом, по ним же потом пишется `at(…)`.

## Шлюз — одним сообщением

```
Уроки: 2 (последний: 2026-10-19 — музыка под скринкаст спокойная)
Звук: запись.mp4
Резка: 65:55 → 45:45 · смысловых резов 43 · переходов зума 322, резов поправлено 18
  1. 03:12 · −36 с · «…ищу, где тут настройки…» — блуждание по меню
  …
План графики: 46 вставок (Д 12 · Э 21 · П 11 · А 2), ~17 мин — export/монтаж/plan.md
| # | Где | Вид | Что | … (таблица целиком)
Пробы музыки (40 с, 04:10–04:50):
  1. export/монтаж/music/проба-1 good for the ghost - Alge.mp4
  2. …
Ответь одним сообщением: что вернуть из резов, что убрать/поменять в плане, какая музыка — или «ок».
```

Ответ «верни 3, 7» → `longform.py restore` → `build` → `zoom_guard` → `timeline.py words`
(анализ заново не гоняется); «№12 убери» → строку из плана; «музыка 2» → трек в
`music.py bed --track`, и если он подошёл — в настройки (`ютуб.музыка.<формат>.трек`).
