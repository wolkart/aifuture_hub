# youtube-edit

Монтирует длинный ролик для YouTube из сырой записи и отдаёт один таймлайн для DaVinci
Resolve, в котором уже всё лежит.

## Зачем это

Отснял — сказал «собери». Дальше всё делает скилл: режет паузы, «э-м» и дубли, ставит
графику на нужные слова, добавляет лёгкий зум на говорящую голову, звуки и музыку. Ты
открываешь таймлайн в Resolve, смотришь, при желании двигаешь и рендеришь сам.
Промежуточных рендеров всего ролика нет.

Главное — проверки до показа. Пустой вход («три секунды тонировка — сидишь, ждёшь»),
картинка, которая висит и ждёт следующей анимации, плашки внахлёст, элемент, который
мелькнул и ушёл, перекошенная композиция, рез посреди наезда камеры — всё это
ловится механически. Скилл не отдаёт таймлайн, пока проверки показывают проблемы.

## Когда срабатывает

«Смонтируй ролик для ютуба», «собери длинный ролик», «наложи графику на запись»,
«отснял — собери», «таймлайн в Resolve со всем готовым».

Нужно только порезать паузы (урок без графики) — это [rough-cut](../rough-cut/).
Вертикальный рилс — [reel](../reel/).

## Что на входе и выходе

**Вход:** запись (FocuSee с зумами или OBS: экран + кружок камеры, голова на весь кадр),
по желанию — отдельный звук.

**Выход** в папке `export/` рядом с записью:
- `<запись>.fcpxml` — таймлайн: V1 — порезанная запись (ссылки на исходник, без
  перекодирования), выше — зум на голове, графика и акценты, ниже — звук и музыка; на
  каждой вставке маркер «что это»;
- `<запись> — таймкоды.md` — что на каком таймкоде;
- `монтаж/` — клипы графики, пробы музыки, план (удаляется, когда ролик отрендерен).

## Как идёт работа

1. Скан кадров и расшифровка — фоном, параллельно.
2. Резка через rough-cut + защита переходов зума: рез никогда не ложится на наезд.
3. План графики и три пробы музыки по 40 секунд.
4. **Одно сообщение тебе:** что вырезано, план графики, пробы. Отвечаешь одним: «верни 3,
   №12 убери, музыка 2, ок». До «ок» ничего не рендерится.
5. Сцены → проверки → рендер клипов графики → зум → музыка → проверки по кадрам → таймлайн.

## Виды графики

| | Что | Когда |
|---|---|---|
| Д | сцена-действие на весь кадр: курсор кликает, терминал печатает, настоящие интерфейсы и логотипы | рассказываешь о том, чего на экране нет |
| Э | поверх экрана: вуаль, графика рядом с тем, что показываешь | экран стоит, а ты объясняешь |
| П | светлая панель: ты уезжаешь влево, справа пункты по словам | говоришь в камеру, перечисляешь |
| А | акцент у головы: чипы, цифра, сообщение | короткий перечень, названная цифра |

## Под себя

Тема, шрифты, звуки — из `reel.settings.json` (общий с рилсами). Музыка и пробы — раздел
`ютуб` того же файла, образец — [assets/settings.example.json](assets/settings.example.json),
ключи — [references/settings.md](references/settings.md).

## Требования

ffmpeg, Node.js (HyperFrames рендерит графику), uv. На macOS — Xcode Command Line Tools
(Apple Vision: где голова в кадре, куда зумить). Для дословной расшифровки с «э-м» —
ключ ElevenLabs в rough-cut (без него — Whisper). Соседние скиллы: rough-cut, reel
(движок рендера), motion-assets (шаблоны панелей и акцентов).

Свободного места — от 20 ГБ: клипы графики, куски таймлайна, кадры рендера.
