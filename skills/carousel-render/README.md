# carousel-render

Рендерит карусель в готовые PNG-карточки 1080×1350 в твоём фирменном стиле.
Вход — `slides.json` с текстом по слайдам, выход — папка файлов и контактный
лист, чтобы одним взглядом проверить ритм.

## Когда срабатывает

«Отрендери карусель», «собери карточки», «сделай PNG из карусели», «свёрстай
слайды», «перерисуй слайд 4», а также просьбы поменять внешний вид: цвет,
шрифт, аватарку, значок.

**Не путать:** текст карусели пишет `carousel-script`, чужие посты качает
`instagram-downloader`. Этот скилл только верстает.

## Что нужно на входе

- **macOS** с Google Chrome и `sips` (входит в систему).
- **`.env`** рядом со скиллом: `THEME_PATH` — путь к `theme.json` со твоим
  стилем, `OUTPUT_DIR` — куда складывать (пусто = рядом со `slides.json`).
  Образец — `.env.template`.
- **Папка темы:** `theme.json` плюс `fonts/` и `assets/` рядом. Шрифты
  скачиваются одной командой: `python3 scripts/fonts.py "<папка темы>"`.

Свой стиль держи **вне репозитория** — тогда публичный хаб остаётся
отгружаемым. В репозитории лежит только нейтральный `themes/example.json`.

## Как работает

```
slides.json + тема
      ↓  build_html.py    самодостаточный HTML: шрифты и картинки как data: URI
      ↓  fit.py           замер переполнения в Chrome → выбор ступени кегля
      ↓  render.py        скриншот в 2× → sips до 1080×1350
      ↓  contact_sheet.py простыня всех слайдов
01.png … NN.png + contact-sheet.png + короткий отчёт
```

С флагом `--preview` промежуточный HTML не удаляется, а рядом появляется
`превью.html` — все слайды живьём в браузере, с девтулзами. Обычно этот HTML
существует только внутри прогона.

Четыре лейаута: `обложка` (виды: текст / со значком / фото на весь кадр),
`тело`, `тело-список`, `CTA`. Подпись и бейдж «ЛИСТАЙ» подставляются по
площадке — у Instagram хэндл одной строкой, у LinkedIn имя с должностью.

## Два принципа, из которых всё остальное следует

**Тема — данные, композиция — код.** Меняются цвета, шрифты, веса, кегли,
картинки, подписи. Расположение блоков внутри карточки зашито в CSS. Поэтому
карусель не может разъехаться от слайда к слайду, а один и тот же вход всегда
даёт побайтово одинаковые PNG.

**Не влезло — скажу, а не ужму.** Кегль спускается по трём заранее заданным
ступеням. Если текст не помещается и на минимальной, скилл сообщает, на сколько
символов резать. Плавная автоподгонка «лишь бы влезло» даёт рваную ленту —
узнаваемость дороже.
