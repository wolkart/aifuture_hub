# layouts.md — схема `slides.json` и словарь лейаутов

Машинный вход рендера. Его отдаёт `carousel-script` (раздел «Рендер-контракт»
в его `references/slide-spec.md`) либо пишет автор руками.

---

## Каркас файла

```json
{
  "meta": { "название": "Агент. Харнес. Loop.", "площадка": "LI", "тема": "theme.json" },
  "слайды": [ … ]
}
```

| Поле `meta` | Значение |
|---|---|
| `название` | Имя папки с результатом |
| `площадка` | `IG` или `LI` — выбирает блок обвязки: хэндл либо имя с должностью, и свою аватарку |
| `тема` | Имя файла темы; резолвится относительно `THEME_PATH` |

---

## Общие правила текста

**`**…**` — выделение, один маркер на все случаи.** Смысл подставляет лейаут:
в теле это жирное начертание, на обложке — акцентный цвет. Не думай про цвет,
думай «что выделить».

**`\n` — принудительный перенос строки.** «Агент.\nХарнес.\nLoop.» разбито
осмысленно, это часть удара; автопереносу такое не отдают.

**Разметка автора экранируется.** Написал в тексте `<b>` — увидишь на карточке
`<b>`, а не жирный шрифт.

**Обвязка не пишется в JSON.** Бейдж «ЛИСТАЙ» и подпись с аватаркой рисует
тема по связке «площадка × лейаут». Единственное поле — `"подпись"` со
значением `показать` / `скрыть`, и оно нужно только чтобы перебить дефолт.

## `обложка`

Тёмная карточка, крупный заголовок Oswald, под ним подзаголовок. Три вида.

| Поле | Обяз. | Описание |
|---|---|---|
| `заголовок` | да | Главная фраза. Крупный кегль, капс |
| `подзаголовок` | нет | Вторая фраза помельче, белым |
| `вид` | нет | `текст` (по умолчанию) / `декор` / `фото` |
| `фото` | при `вид: фото` | Путь к снимку относительно `slides.json` |
| `низ` | нет | Мелкая строка под текстом («СОХРАНИ, ЧТОБЫ НЕ ПОТЕРЯТЬ») |

```json
{ "№": 1, "лейаут": "обложка",
  "заголовок": "Агент.\nХарнес.\nLoop.",
  "подзаголовок": "Звучит как высшая математика. Внутри — три простые штуки. Объясняю." }
```

Вид `декор` вешает значок из темы (`ассеты.спарк`) в свободный верхний угол.

Вид `фото` кладёт снимок на весь кадр, текст уходит вниз поверх затемнения.
**Подпись с аватаркой при этом гасится автоматически** — автор уже на снимке,
дублировать нелогично. Вернуть: `"подпись": "показать"`.

**Автогашение верно только для портрета автора.** Если на обложке не он, а
скриншот, снимок экрана, терминал или любая иллюстрация — подпись обязана
остаться: аватарка есть на всех остальных карточках, и её пропажа именно на
первой читается как сбой, а не как приём. Правило простое: **на снимке нет
автора → ставь `"подпись": "показать"`.** Ставь сразу, а не после того, как
карточку забракуют.

```json
{ "№": 1, "лейаут": "обложка", "вид": "фото", "фото": "beach.jpg",
  "заголовок": "У **Claude** есть ADHD-режим, который взламывает твой **дофамин**.",
  "низ": "СОХРАНИ, ЧТОБЫ НЕ ПОТЕРЯТЬ" }
```

## `тело`

Светлая карточка, абзацы Montserrat, блок отцентрован по вертикали.

| Поле | Обяз. | Описание |
|---|---|---|
| `блоки` | да | Список абзацев, 1–4 штуки |
| `нить` | нет | `true` вешает стрелку `⇢` в конец последнего абзаца |

```json
{ "№": 3, "лейаут": "тело",
  "блоки": [
    "Мозг, который только **болтает**",
    "Попроси ChatGPT собрать сайт. Он выдаст код и **замолчит**.",
    "А теперь смотри"
  ],
  "нить": true }
```

Нить — приём «разрез фразы через свайп» из `carousel-script/references/carousel-backbone.md`.
Поэтому это поле, а не символ в тексте: стрелка рисуется элементом и всегда
выглядит одинаково.

---

## `тело-список`

Светлая карточка. Отдельный лейаут, а не абзацный: у него свой ритм отступов
между пунктами и подвал курсивом, которые иначе пришлось бы имитировать руками
на каждой карточке.

| Поле | Обяз. | Описание |
|---|---|---|
| `заголовок` | да | Название блока |
| `подзаголовок` | нет | Строка-боль под заголовком |
| `пункты` | да | Список вида `**имя** — что даёт` |
| `подвал` | нет | Итоговая строка курсивом со стрелкой |

```json
{ "№": 4, "лейаут": "тело-список",
  "заголовок": "Разработка",
  "подзаголовок": "Проект не разваливается на пятой правке.",
  "пункты": [
    "**superpowers** — не бросишь на середине: сам разбивает работу на шаги",
    "**context7** — код заводится с первого раза"
  ],
  "подвал": "→ Твой отдел разработки" }
```

## `промпт`

Светлая карточка: номер, стадия, строка-выгода и белый блок с текстом, который
читатель забирает себе. Текст промпта набирается моноширинным — так видно, что
это речь для машины, и не теряются плейсхолдеры.

| Поле | Обяз. | Описание |
|---|---|---|
| `заголовок` | да | Название стадии |
| `промпт` | да | Текст промпта. Переносы строк — как в жизни, `\n` |
| `номер` | нет | Что печатать крупно акцентом: «01». Нет — строки нет |
| `подзаголовок` | нет | Строка-выгода: зачем эта стадия |

```json
{ "№": 2, "лейаут": "промпт", "номер": "01",
  "заголовок": "Описание продукта",
  "подзаголовок": "Пока это не написано, ты не строишь, а угадываешь.",
  "промпт": "Напиши описание продукта. Код НЕ пиши.\n\nЧто строим: [ОПИШИ ИДЕЮ]" }
```

**Плейсхолдеры `[В КВАДРАТНЫХ СКОБКАХ]` красятся сами** — размечать их `**…**`
не нужно. Пиши промпт ровно так, как отдал бы его человеку.

Кегль берётся из `ступени.промпт`. Ключа нет в теме — работает на значениях по
умолчанию, тему править не обязательно.

---

## `CTA`

Тёмная карточка, тот же градиент, что у обложки. Подпись стоит сверху и
крупная — это герой карточки, а не мелкая сноска. Бейджа «ЛИСТАЙ» нет.

| Поле | Обяз. | Описание |
|---|---|---|
| `блоки` | да | Абзацы призыва, по центру |

```json
{ "№": 7, "лейаут": "CTA",
  "блоки": [
    "Хочешь разбираться в AI без магии и хайпа — подписывайся.",
    "Разбираю по-честному, как оно устроено на самом деле."
  ] }
```

---

## Словарь закрыт

Пять значений: `обложка`, `тело`, `тело-список`, `промпт`, `CTA`. Расширять
внутри карусели нельзя — незнакомый лейаут это ошибка, а не повод
сымпровизировать.

Композиция лейаутов живёт в `layouts/*.css` и меняется только правкой скилла.
Это цена за гарантию, что карусель не разъедется от слайда к слайду.
