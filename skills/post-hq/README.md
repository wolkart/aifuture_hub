# post-hq — пост голосом автора

Из надиктовки, черновика или идеи — готовый пост голосом автора для Telegram, Threads/X, LinkedIn или подписи Instagram. Скилл работает как редактор: порядок, сокращение, проверка фактов и логики, подсказка по форматированию. Голос берётся из **образцов постов автора**, а не из свода правил.

## Почему так

До 2026-11-27 на один пост грузилось ~12 000 слов правил (законы текста, Ильяхов, Огилви, Хормози, ревьюер). Ошибки рождались из самих правил: буквализм, «перевод» авторских терминов, срезанные авторские оценки. Практика гострайтеров и исследования (IFScale, «curse of instructions», рекомендации Anthropic про примеры) сходятся: голос держат 10–20 настоящих текстов и короткая страница заметок, а не длинный список запретов.

## Когда срабатывает

«Напиши пост», «пост в телегу», «прогрев», «продающий пост», «оформи в моём голосе» — или когда автор присылает надиктовку, тезисы, черновик. Также вызывается из `content-machine` как формат «пост».

## Что внутри

| Файл | Содержимое |
|------|-----------|
| `SKILL.md` | Роль редактора, что читать перед работой, три строки под текстом (Вырезано / Обещания / Логика), форматирование, выдача в волт |
| `references/platforms/telegram.md` | Конвенции Telegram: длина, первая строка, вёрстка, форматирование, концовка в своём канале |
| `references/platforms/threads-x.md`, `linkedin.md`, `instagram-caption.md` | Конвенции остальных площадок |
| `references/purposes/selling.md` + `frameworks/hormozi.md`, `ogilvy.md` | Только по прямой просьбе: продающий пост, запуск, оффер |

Голос — `skills/brand-voice/references/brand-voice.md` (одна страница) + файл образцов автора (путь в `CLAUDE.md` проекта).

## Что НЕ делает

Скилл не постит и не доставляет контент — это задача слоя рантайма. Не переписывает авторский замысел: при конфликте побеждает автор. Не делает визуал карточек — делегирует `carousel-script`.

## Фазы

**Фаза 1 ✅:** Telegram (контентный + продающий пост).

**Фаза 2 ✅:** Threads/X, LinkedIn, Instagram-подписи — активны. Модули площадок по единому контракту платформы: `references/platforms/threads-x.md`, `linkedin.md`, `instagram-caption.md`.
