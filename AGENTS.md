# Codex guidance for AI Future Hub

@CLAUDE.md

`CLAUDE.md` is the canonical project guidance for this repository. Before
working here, read it in full: it defines repository boundaries, the
public/private split, and the workflow for creating or changing skills. This
file extends that guidance only with Codex-oriented instructions; it does not
replace or duplicate `CLAUDE.md`.

## Skills

- Treat each `skills/<name>/SKILL.md` as the canonical instruction for that skill.
- Read the relevant `SKILL.md` and only the references it routes you to before
  using or changing a skill.
- Keep this repository platform-neutral. Do not rewrite skill content merely to
  mention a particular model provider; adapt only provider-specific paths or
  tool calls when a runtime requires it.

## Safety

- This is a public distribution hub. Do not add private niche information,
  author voice, credentials, or customer material.
- Capture skill and harness improvements in `BACKLOG.md`; make intentional
  changes to skills from this repository.
