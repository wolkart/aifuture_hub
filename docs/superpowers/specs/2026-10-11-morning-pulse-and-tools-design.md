# Утро Hermes: НейроПульс голосом автора + «Тулзы дня»

Дата: 2026-10-11. Статус: дизайн утверждён автором по частям в разговоре, спек на ревью.

## Проблема

Вопрос автора: где брать новые инструменты (GitHub, скиллы, харнесы, открытые модели), которые блогеры показывают через 2–7 дней после выхода. Разбор выявил четыре дыры.

1. **У `ai-research` нет источников инструментов.** `references/sources.md` — СМИ, блоги лабораторий, рассылки. Нет GitHub, Hacker News как витрины проектов, Reddit-сабов про Claude Code, Simon Willison. Papers with Code из Tier-3 закрыт в 2025 году (редирект на HF Papers).
2. **НейроПульс приносит статьи, а не инструменты.** Утренний дайджест Hermes (`daily-ai-news-club-digest`, 07:00) 2026-10-11 дал 6 пунктов: 5 ссылок на The Verge и Google News, один репозиторий — случайно. Агент сам выбирает, что искать, и веб-поиск по «новым инструментам» отдаёт статьи о них.
3. **Выводы по шаблону и узкий фильтр.** Промпт требует к каждой новости практический вывод для билдеров — выходит «для билдеров это значит…» в каждом пункте. Фильтр «только важное для практических AI-билдеров» режет хайповые новости и рыночные сдвиги, которые автору интересны.
4. **Голос устарел.** Hermes пишет «примерно в стиле Артёма»: в `~/.hermes/skills/aifuture/` лежит ручная копия скиллов хаба от 2026-07-29. Из 19 файлов `brand-voice` / `post-hq` / `ai-research` 11 с тех пор изменились, четырёх законов (`copy-law`, `craft-law`, `evidence-law`, `revision-law`) нет вовсе. Любая новая копия разойдётся с хабом так же.

## Решения (утверждены автором 2026-10-11)

1. **Два утренних сообщения.** ⚡ НейроПульс в 07:00 — новости, как сейчас, но голосом автора и с живыми выводами. 🛠 Тулзы дня в 07:15 — отдельное сообщение только про инструменты.
2. **Агент по рецепту, без скрипта сбора.** Рецепт — markdown в скилле: точные команды к API, проверка на накрутку, протокол «уже показывал». Агент сам выполняет команды через терминал. Обоснование: выигрыш скрипта (одни и те же источники, цифры из API) достигается тем, что агенту дают нужные команды. Скрипт видит только прописанное и требует починки при каждой смене API — у автора уже был опыт кучи скриптов для Hermes, которые проиграли агенту. **Порог перехода к скрипту:** строка «Проверено» неделю показывает пропуски источников, повторы вчерашнего или дорогой сбор — тогда в код уходит только сбор, отбор и текст остаются агенту.
3. **Hermes читает скиллы из клона хаба.** Ручная копия уходит в архив. Один источник правды: правка `brand-voice` в хабе назавтра доходит до обоих сообщений.
4. **Голос — `brand-voice` хаба, выводы — по желанию.** Три вида вывода: подколоть, высказать мнение, связать две новости в одну мысль. Нечего сказать — пункт без вывода. Мнение подаётся как мнение (`evidence-law`). Шаблон «для билдеров это значит» уходит.
5. **В «Тулзах дня» — рекомендация «🔥 потыкать».** Не всем пунктам, а 0–2 самым перспективным: для билдеров, кода или чтобы разобраться в новом приёме с нейросетями. С причиной и примерным временем.
6. **Публичное — в хабе, личное — на сервере.** Хаб получает обобщённый рецепт и правила выводов. Названия «НейроПульс» и «Тулзы дня», AI Future Club, темы автора и чат доставки живут только в промптах задач Hermes.

Отклонено по ходу: отдельный радар вместо НейроПульса, слияние тулз в НейроПульс, отдельная задача «Лично тебе» (потыкать / контент / заказы) — её роль взяла пометка 🔥 внутри «Тулз дня».

## Хаб: что меняется

Это новый режим существующего скилла, не новый скилл, поэтому маршрут через `meta-prompt` не применяется.

### `skills/ai-research/SKILL.md`

- **`description`:** добавить триггеры инструментов — «что нового на GitHub», «какие инструменты/тулзы вышли», «что потыкать из нового».
- **Роутер:** строка `radar` — «инструменты», «тулзы», «GitHub», «что потыкать», «репозитории».
- **Раздел режима `radar`:** коротко, задача + ссылка на `references/radar.md`. Source-лесенка (Perplexity → WebSearch) для `radar` не действует: веб-поиск отдаёт статьи, а режиму нужны сами репозитории, поэтому источники берутся командами из рецепта.
- **Режим `digest`:** шаг «выводы» со ссылкой на правила в `output-modes.md`; фильтр значимости включает хайп и рыночные сдвиги, а не только практическое.

### `skills/ai-research/references/radar.md` — новый, рецепт

**Источники и команды.** Каждый источник — одна команда. Отказ источника не останавливает сбор: он помечается ✗ с причиной.

| Источник | Что ловит | Команда (суть) |
|---|---|---|
| GitHub Search | новые репозитории за 7 дней, быстро набирающие звёзды | `gh search repos --created ">=<дата-7>" --stars ">=100" --sort stars --limit 30 --json fullName,description,stargazersCount,createdAt,url`; по узким темам `--topic <t>` с порогом 30; без `gh` — тот же запрос в `api.github.com/search/repositories` |
| GitHub Trending | старые проекты, которые вдруг выстрелили | страница `github.com/trending?since=daily`, агент читает «stars today» |
| Show HN | что авторы сами принесли на HN | `hn.algolia.com/api/v1/search?tags=show_hn&numericFilters=created_at_i>…,points>=30` (`>` в URL кодировать как `%3E`) |
| Reddit | открытые модели, скиллы, харнесы | RSS `reddit.com/r/<sub>/top/.rss?t=day` для LocalLLaMA, ClaudeAI, ClaudeCode; JSON с серверных IP отдаёт 403 |
| Hugging Face | трендовые модели | `huggingface.co/api/models?sort=trendingScore&limit=20` |
| Simon Willison | инструменты, которые кто-то уже попробовал руками | RSS `simonwillison.net/atom/everything/`, последние 48 ч |

**Темы по умолчанию:** агенты и харнесы; скиллы и плагины для Claude Code, Codex и других агентов; MCP-серверы; открытые модели и их запуск; ассистенты и боты по базе знаний (RAG). Вызов может задать свои темы — они заменяют дефолт.

**Пороги на старте:** новые репозитории ≥100★ за 7 дней, по узким темам ≥30★, Show HN ≥30 очков за сутки. Калибруются по первой неделе выдачи.

**Проверка кандидатов** (до 8). README есть и объясняет, что это; последний коммит свежий; issues и PR от разных людей; кто автор. Признаки накрутки: тысячи звёзд при почти нулевых issues и форках; пачка однотипных репозиториев от свежего аккаунта. Такое выкидывается или помечается ⚠️. Остаётся 3–5.

**«Уже показывал».** Если вызов передал путь к файлу: перед отбором отсеять ссылки из файла, после выдачи дописать показанные (`ГГГГ-ММ-ДД URL`), записи старше 30 дней удалить. Без пути шаг пропускается.

**🔥 потыкать** — 0–2 пункта, все три условия: решает задачу, которую билдер или кодер реально делает, или открывает новый приём в работе с нейросетями; ставится и запускается примерно за 30 минут; проект живой, не ⚠️. К пометке — одна строка: почему и сколько времени.

**Выдача.** Пункт: название — что это одной фразой — зачем это читателю или вывод по правилам `digest` — ★ из API — ссылка. Последняя строка обязательна: `Проверено: GitHub ✓ · Trending ✓ · HN ✓ · Reddit ✓ · HF ✓ · Willison ✗ <причина>`. Это форсирующая строка: пропуск источника виден в самом сообщении. Нового нет — честно сказать «нового нет» (в Hermes агент отвечает `[SILENT]` по протоколу крона, строку тогда не пишет).

### `skills/ai-research/references/output-modes.md`

- **`digest`:** поле «Почему важно» заменить на «Вывод (по желанию)» с тремя видами (подколоть / мнение / связать две новости), правилом «нечего сказать — без вывода» и подачей мнения как мнения. Обновить пример.
- **`radar`:** новый раздел — шаблон пункта, пометка 🔥, строка «Проверено», пример на 2 пункта.

### `skills/ai-research/references/sources.md`

### Витрина и тесты

**Подготовка (откат — из этих копий):**

**Подключение хаба:**
- `git clone https://github.com/wolkart/aifuture_hub /opt/data/hub` (репозиторий публичный, ключи не нужны), владелец — `hermes`;
- `config.yaml`: `skills.external_dirs: [/opt/data/hub/skills]`;
- `mv /opt/data/skills/aifuture /opt/data/skills/.archive/aifuture-2026-07-29` — Hermes сам складывает старые скиллы в `.archive/`.

**⚡ НейроПульс** (`daily-ai-news-club-digest`, `b65462e35323`, 07:00):
- скиллы: `research-intelligence-workflows` → `ai-research`, `brand-voice`;
- промпт: шаг 0 `git -C /opt/data/hub pull --ff-only`; режим `digest` скилла `ai-research`; голос по `brand-voice` (`copy-law` + `brand-voice.md`) и правилам Telegram из `post-hq/references/platforms/telegram.md`; выводы по правилам `digest`; хайп и рыночные новости разрешены;

**🛠 Тулзы дня** (новая задача `tools-of-the-day`, 07:15):

## Проверка

1. **Локально:** запустить `ai-research` в режиме `radar` на маке. Ожидание: 3–5 пунктов, у каждого ★ и ссылка на репозиторий, 🔥 не больше двух, строка «Проверено» со всеми шестью источниками.
2. **Hermes подхватил хаб:** `hermes skills list` показывает `ai-research` и `brand-voice` из `/opt/data/hub/skills`, дублей с архивом нет.
3. **Прогон задач:** `hermes cron run` для обеих задач, вывод в `cron/output/<id>/`, сообщения пришли в Telegram. НейроПульс: шапка и подвал на месте, выводы есть не везде и не по шаблону. Тулзы дня: файл `tools-seen.txt` заполнен.
4. **Повторный прогон «Тулз дня»** в тот же день: показанное не повторяется — либо новые пункты, либо `[SILENT]`.
5. **Через неделю:** по строкам «Проверено» и выдаче откалибровать пороги и решить, нужен ли скрипт сбора (порог — в решении 2). Записать строкой в `BACKLOG.md`.
